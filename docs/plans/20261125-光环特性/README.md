# 光环特性

## 问题

现有特性只作用于兵种自己，例如龟甲阵是自己所受的远程伤害减少。想做「带盾牌的步兵掩护身边的友军，让周围一定范围内的单位所受远程伤害减少」这类效果，现在没有办法表达。

## 方案概述

给特性加上「光环」：特性可以声明一个光环，写明半径、作用对象和加成内容。模拟层定期找出光环范围内的友军，给他们挂上加成。光环是通用机制，不针对具体兵种；本计划先落地第一种加成「所受远程伤害倍率」，以后的旗手鼓舞士气、号手加快攻击等，都按同样写法往里加加成种类。

光环仍是特性，按点数机制计点：在标准混编军的对应位置上实测它值几点，写进价目表。

## 关键设计决策

- **光环是特性的一部分**：特性定义里可带光环参数（半径、加成种类与数值），兵种挂上这个特性就有光环。系统只认特性上的光环数据，不认具体兵种。理由：沿用「系统只认原型与特性」的规则，配新兵种只要挂特性。
- **作用对象是光环来源以外的己方单位**：不含来源自己。理由：来源自己的防护已经由它自己的举盾、护甲与特性表达，再给自己加会重复。
- **同类光环不叠加，取最强的一个**：一个单位同时在几个同类光环里时，只取加成最大的那个。理由：盾兵扎堆时不会把周围的单位叠到刀枪不入，加成上限就是单个光环的数值，计点也不会因扎堆而失真。
- **来源溃逃或阵亡时光环失效**：受益者自己在溃逃时照样受益。理由：光环表达的是来源在场掩护，来源跑了就没有掩护；受益者溃逃时仍在盾后，没有理由失去。
- **定期更新**：每隔一个固定的短间隔重新判定谁在光环里，不是每帧都算。理由：千人会战下每帧两两判距离开销太大，加成慢半拍对玩法没有影响。
- **第一种加成「所受远程伤害倍率」的结算位置**：在伤害结算里与龟甲阵同一层相乘，只对远程攻击（投射物）生效。理由：与已有的「所受远程伤害」修正口径一致。
- **计点**：光环特性的价格按特性测价规程，在标准混编军里该兵种所在位置的全员挂上它实测。已知边界：价值是在标准混编军的阵型与构成下测的，远程兵比例更高的阵营里实际价值会偏高，属于价目表按单项可加计账的既有边界。

## 01 光环机制与远程掩护

> 目标: 特性可以声明光环；带光环特性的单位让范围内的己方单位获得加成，第一种加成是所受远程伤害倍率；光环特性进价目表计点。
> 完成判据: 定义一个带「所受远程伤害倍率」光环的特性并挂到一个测试用兵种上：范围内的己方单位受到的远程伤害按倍率减少，范围外、敌方、来源自己不受影响，近战伤害不受影响；同时处在两个同类光环里只取最强的一个；来源溃逃或阵亡后加成在下一次更新时消失；受益者溃逃时仍受益。测量工具能给光环特性测价，价目表里有它的价格且带过期指纹；兵种挂上它时估算点数按价目计入。兵种提示里显示光环（半径与加成）。类型检查与测试通过。

依赖 `docs/product/units.md`「点数机制」所述的特性计点（兵种数值建模已合入）。

### 技术设计

- [ ] 特性定义增加可选的光环参数：半径，加成种类，加成数值
- [ ] 每个单位记录当前生效的光环加成（按加成种类各一个值），由光环系统定期写入
- [ ] 光环系统：按固定间隔遍历带光环的存活、未溃逃单位，给范围内的其他己方单位写入加成，同类取最强；不在任何光环里的单位恢复为无加成
- [ ] 伤害结算：远程攻击对单位造成的伤害，乘以受害者当前的「所受远程伤害」光环加成，与龟甲阵同一层
- [ ] 价目表：光环特性按特性测价规程计价，光环参数纳入测量指纹

### 实现方案

- [ ] 特性定义与展开时的校验（半径与数值的合理范围）
- [ ] 光环系统接入每帧的系统更新顺序，在伤害结算之前
- [ ] 伤害结算接入加成
- [ ] 测量工具支持给光环特性测价，规程写进文档
- [ ] 兵种提示显示光环
- [ ] 测试：作用范围与对象、同类取最强、来源溃逃与阵亡、受益者溃逃、近战不受影响、计点

### 开发者提示

- **可复用能力**：特性注册与展开（特性定义、合成、兵种的特性列表）；伤害结算里已有的龟甲阵「所受远程伤害」修正；测量工具的特性测价与价目表生成；兵种提示的生成。
- **开发要点**：
  - 系统代码不出现具体兵种或原型 key，只读特性上的光环数据（编码规范「内容层与点数」）。
  - 光环改了伤害结算，会让价目表的测量指纹过期：按 `docs/coding-standards.md`「内容层与点数」用测量工具重量价目表，再重算预算与各阵营级数。
  - 半径与加成数值放在特性定义里，更新间隔等调行为的数值放进规则表。
  - 规则与数值以产品文档为准，改完同步 `docs/product/units.md`「兵种特性」「点数机制」与 `docs/product/combat.md`。
- **参考文档**：`docs/product/units.md`「兵种特性」「点数机制」、`docs/product/combat.md`「伤害」、`docs/unit-stat-model.md`、`docs/coding-standards.md`

## 待定

- **挂到哪些兵种、数值多少**：哪些现有兵种（例如刀盾兵、军团步兵、辅助矛兵、持盾矛兵这类持盾步兵）带这个光环、半径与倍率取多少，属于阵营配点，待定；挂上之后按价目表计点，阵营点数随之重算。
- **选中时是否在地上画出光环范围**：本计划只在兵种提示里显示。
- **更多加成种类**：士气、攻击间隔、移动速度等光环，按同一机制往加成种类里加，各自另行计划。
