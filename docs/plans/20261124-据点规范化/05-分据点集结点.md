# 05 分据点集结点

> 目标: 每个据点有自己的援军集结点，也可以一次给所有据点设同一个集结点，见 [README.md](README.md)「集结点」。
> 完成判据: 选中据点 A 后用 R + 左键设集结点，只有 A 新出的援军开赴那里，其他据点的援军留在原地。没选据点时 R + 左键，所有据点新出的援军都开赴同一点。Shift + R 在选中据点时只取消它的，没选据点时全部取消。选中敌方或中立据点时按 R 不响应并给出提示。据点易主后集结点被清除。电脑每占下一个据点就把它的集结点设在出发阵地，援军照旧先到出发阵地集结。类型检查与测试通过。

不依赖其他里程碑。

## 技术设计

- [ ] 集结点由每方一个改为每个据点一个。

## 实现方案

- [ ] 指令：选中己方据点时，R + 左键设、Shift + R 取消这个据点的集结点；没选据点时对所有据点设、取消；选中敌方或中立据点时不响应，并提示只能给己方据点设。
- [ ] 显示：选中据点时显示它的集结点。
- [ ] 据点易主时清除它的集结点，新主人在这里出的援军留守。
- [ ] 电脑：开局把所有据点的集结点设在出发阵地，之后每占下一个据点也这样设。
- [ ] 界面：快捷键说明、按钮提示与教程，随操作一起更新。
