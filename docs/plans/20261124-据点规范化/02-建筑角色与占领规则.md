# 02 建筑角色与占领规则

> 目标: 建筑按 [README.md](README.md)「建筑角色」分为军事建筑、城防、普通建筑；占领规则改为 [README.md](README.md)「占领」所述。
> 完成判据: 普通建筑不能被选为攻击目标：右键攻击、单位自动索敌、电脑选目标都不会选它，投射物与范围伤害也不伤它。敌占或中立据点里还有军事建筑立着时不能读秒，全部摧毁后才能读秒。中立据点的军事建筑会向双方放箭，直接右键就能攻击，自动索敌也会打它；它们不在交战时会自行修复和重建，进攻方在中立据点范围内读秒期间不会重建。摧毁中央建筑后据点不易主、不变成废墟，只停止援军；中央建筑重建之后援军恢复。资源点的建筑不自行修复。电脑攻占据点时会先拆军事建筑。类型检查与测试通过。

依赖 [01-据点构成与胜负.md](01-据点构成与胜负.md) 的据点构成。

## 技术设计

- [ ] 建筑表为每种建筑声明角色：军事建筑、城防、普通建筑。
- [ ] 占领的前提：据点里还有立着的军事建筑（不论属于敌方还是中立）就不能读秒。替换现有的「敌占城邦、营寨要先拆主建筑」与「资源点、村庄要先拆光对方箭塔」两条。
- [ ] 中立的军事建筑放箭，目标是双方单位；玩家和电脑都把它当作敌方建筑攻击（直接右键、自动索敌）。
- [ ] 交战判定：中立据点范围内有任何一方的单位就算交战。
- [ ] 去掉废墟状态：中央建筑被毁时，据点只停止出援军，不易主，建筑也不转为中立。

## 实现方案

- [ ] 普通建筑不进入任何攻击目标：玩家的攻击指令、单位自动索敌、电脑选目标都排除它；投射物命中与范围伤害都跳过它。
- [ ] 中央建筑按现有的自行重建立起来之后，援军计时恢复。
- [ ] 资源点的建筑不再自行修复；自建的哨塔被毁后仍要花资源重建。
- [ ] 中立据点的建筑和有主据点一样：不在交战时自行修复，倒塌的也会重建（中立方没有资源，按原速修）。
- [ ] 电脑：攻占据点时先拆军事建筑，再肃清、读秒。
- [ ] 界面：占领提示和据点面板里关于主建筑、废墟的说明，以及中立建筑的攻击方式，随规则一起更新。

## 开发者提示

- **可复用能力**：
  - 城防工事（石墙）的「打不动」在伤害结算、单位索敌、攻击指令、目标校验等多处各自判断。普通建筑不可攻击要沿用同样的判断，逐处补齐。
  - 据点建筑的自行修复与倒塌重建在据点系统里，有现成的「修满之前不放箭」状态。
- **开发要点**：
  - 现有的「据点是否可以读秒」判断集中在一处，里面有主建筑先拆和箭塔两条，改成按军事建筑判断即可。
  - 中立的放箭建筑已经在放箭列表里，只是放箭时因为中立被跳过；放箭时按归属找敌人的查找也要改成双方都找。
  - 交战判定现在只统计据点主人的敌兵，中立据点恒为 0。
  - 废墟状态在界面、渲染、电脑战略和据点系统里都有分支，去掉时一并清理。
