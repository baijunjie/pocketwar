# 03 据点范围矩形化

> 目标: 有围墙的据点以围墙圈出的矩形作为据点范围，没有围墙的据点仍用圆形的占领圈，见 [README.md](README.md)「据点范围」。
> 完成判据: 选中城池或营寨时，高亮的是围墙矩形；矩形内有敌方单位时不能读秒，据点算作交战；矩形外的敌人不影响占领和交战判定；读秒进度按矩形显示；有围墙的据点地上不再常驻画圈。资源点和临时据点的表现不变。类型检查与测试通过。

依赖 [01-据点构成与胜负.md](01-据点构成与胜负.md)（营寨都有了木栅）。

## 技术设计

- [ ] 统一的「单位是否在据点范围内」判定：有围墙的据点按围墙矩形（含墙），没有围墙的按占领圈。

## 实现方案

- [ ] 占领前的肃清、交战判定（含中立据点）、休整都改用统一判定。
- [ ] 渲染：有围墙的据点不再常驻画占领圈；选中高亮和读秒进度按据点范围的形状绘制。
- [ ] 其余按占领圈半径判断远近的地方逐一核对，改用据点范围：扎营选址离别的据点多远、电脑判断据点附近的敌情、守备范围等。

## 开发者提示

- **可复用能力**：
  - 世界里已经有一张「围墙内格子属于哪个据点」的网格。休整和远程守军自动登城已经在用它，可以直接作为矩形判定的依据。
- **开发要点**：
  - 现在占领计数按圆算，休整按围墙之内算，两套判定写在同一个循环里，统一时注意别漏掉其中一处。
