# 对战校准

> 目标: 用无头对战实测校准估值函数的参数与兵力占用，并用阵营循环赛验收平衡。
> 完成判据: 校准工具能对任一原型的任一维度或特性跑出「估值函数算它值 k 点」与「生命 +k 级」的战果差，并给出修正后的步长或价目；兵力占用由各原型基准与标准混编军打成平手所需的人数给出；按实测值更新参数与兵力占用、重新调平预算后，电脑对电脑的多种子循环赛里任一对阵的胜率都在 40–60% 内。

依赖 [05-阵营点数预算.md](05-阵营点数预算.md) 的阵营点数计算与 [03-兵种表点数化.md](03-兵种表点数化.md) 的估值函数、标准混编军。

## 技术设计

- [ ] 校准对战：被测兵种 N 个对标准混编军；以生命为一般等价物，比较「某维度或特性加到估值函数算出的 k 点」与「生命 +k 级」的战果
- [ ] 战果相同则该项定价准确；不同则修正它的步长或价目，直到相同
- [ ] 要校准的项：机动、射程、纪律、冲击的步长，按包定价的特性，节奏、护甲、破甲、克制的估值（验证估值函数与参考军是否贴合实战），兵员与援军维度的换算
- [ ] 兵力占用校准：对每个原型找出与同一支标准混编军打成平手所需的基准单位人数，占用值与这个人数成反比，近战步兵定为 1
- [ ] 阵营循环赛：电脑对电脑、多种子全对局，任一对阵胜率在 40–60% 内才算通过

## 实现方案

- [ ] 搭校准对战：按「原型 + 级数 + 特性」临时造兵种，摆被测一方对标准混编军，输出战果
- [ ] 逐原型逐项校准，更新阶梯步长、特性价目与估值函数的参数
- [ ] 校准兵力占用
- [ ] 参数与兵力占用变动后，重新算各兵种净点数与阵营点数，重新调平到预算
- [ ] 跑循环赛；不过线的对阵回到调数值，直到全部过线

## 开发者提示

- **可复用能力**：测试里已有平地对冲与 AI 对 AI 整局两种平衡统计，整局统计支持指定轮数与起始轮次，便于多进程并行；平地无头世界的测试辅助。
- **开发要点**：
  - 整局统计耗时很长，默认测试不跑，用环境变量开启。
  - 校准对战用平地无头世界，昼夜天气保持关闭，避免风、雨雪把战果搅乱。
  - 战果用双方剩余生命占开局的比例之差计，不用战力估值，也不用兵力份数（两者本身是被校准的对象）。
  - 参数变了，产品文档里的数值表跟着变，改完同步。
