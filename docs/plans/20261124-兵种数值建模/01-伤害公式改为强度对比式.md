# 伤害公式改为强度对比式

> 目标: 单位与建筑受击都按同一条强度对比式结算：重击穿甲、快攻怕甲，但没有打不动的情况，每点护甲的价值可以定价。
> 完成判据: 单元测试覆盖新公式（破甲、克制倍率与对建筑倍率进入打击强度、溃兵不计护甲、雪天护甲减半、不计护甲的攻击、没有保底）；阵营对冲统计里各阵营的偏差不大于改动前；全部测试通过。

## 技术设计

- [ ] 打击强度 d = 攻击 × 克制倍率；打建筑时 d = 攻击 × 对建筑倍率
- [ ] 伤害 = d × d ÷（d + c × 护甲 ×（1 − 破甲）），c = 2，作为规则数值登记；单位与建筑共用，不设保底
- [ ] 不计护甲的攻击（投石、火箭、火炮）按护甲 0 结算；火把打建筑仍按材质倍率，不走护甲
- [ ] 溃兵不计护甲并加倍率、雪天据点外护甲减半、据点升级的护甲加成：规则不变，作用在新公式的护甲项上
- [ ] 举盾、龟甲阵、林地、城墙垛口、等级防御这些后续倍率的顺序与数值不变
- [ ] 现有兵种与建筑的护甲数值原则上沿用，只调整对冲统计里偏差变大的

## 实现方案

- [ ] 改动前跑一次阵营对冲统计，记下各阵营的偏差作基线
- [ ] 把单位受击与建筑受击的护甲结算换成同一个强度对比式
- [ ] 重跑对冲统计，与基线对照；偏差变大的阵营调整护甲数值后再跑

## 开发者提示

- **可复用能力**：测试里已有阵营两两对冲与 AI 对 AI 整局两种平衡统计（用环境变量开启，耗时较长）；平地无头世界与按秒推进的测试辅助。
- **开发要点**：
  - 规则数值集中在内容层的规则表，系统里不写死数字。
  - 箭塔放箭、副武器、冲撞、立枪反伤、范围杀伤、践踏都走同一个单位受击结算，公式一改，它们对重甲单位的伤害也跟着变，对照时一并核对。
  - 现在单位受击保底 1、建筑受击保底 1（远程 0.5），新公式恒为正。会碰到保底的只有单位受击；建筑受到的计护甲伤害只来自蝎弩和战象（人形单位打建筑是扔火把，不计护甲），都远在保底之上，取消保底不影响现有的建筑数值。
  - 高级形态的护甲 +2 与界面详情面板里的护甲数值含义随公式改变。
  - 规则与数值以产品文档为准，改完同步。
