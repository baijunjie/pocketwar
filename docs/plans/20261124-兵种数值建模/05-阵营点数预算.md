# 阵营点数预算

> 目标: 每个阵营的阵营点数相同：点数按比重发到每份兵力上，兵员与援军数量也用同一笔预算购买；级数范围与单兵种上下限从这里开始执行。
> 完成判据: 测试断言四个阵营的阵营点数都等于预算、各兵种净点数在 −8…+16 内、各维度级数在范围内、编制比重之和为 1；兵员与援军倍率只能由阵营级维度的级数给出；按预算调平后重跑阵营对冲与 AI 对 AI 整局统计并记录结果。

依赖 [03-兵种表点数化.md](03-兵种表点数化.md) 的净点数与越限清单、[04-兵力占用与编制.md](04-兵力占用与编制.md) 的兵力比重。

## 技术设计

- [ ] 标准据点组合（各类据点的数量）与合成比例（开局兵力占整局预期总兵力的比例）：由电脑对电脑的整局统计实测，取各类据点的平均出兵量与开局兵力之比
- [ ] 比重表：开局编制比重与预期援军比重按合成比例合成；预期援军比重由标准据点组合与该阵营的援军编成算出
- [ ] 阵营级维度：兵员（开局兵力）、援军（援军数量），用级数表达；总兵力 +3.5% 约合平均每份 1 点，兵员按合成比例、援军按余下的比例折算
- [ ] 阵营点数 = Σ 兵种净点数 × 该兵种在比重表中的比重 + 阵营级维度花费的点数
- [ ] 预算：把现有四阵营倒推出的阵营点数取中位数，各阵营的阵营点数都等于它
- [ ] 单兵种净点数上下限 −8…+16；各维度的级数范围按倒推出的分布核定后执行
- [ ] 兵种数量与原型覆盖不作统一要求

## 实现方案

- [ ] 跑整局统计，定下标准据点组合与合成比例
- [ ] 写阵营点数的计算，能列出各阵营每个兵种的比重、净点数与贡献
- [ ] 倒推现有四阵营的阵营点数（把现有兵员、援军倍率折成级数），取中位数作预算
- [ ] 对照越限清单核定各维度的级数范围
- [ ] 逐阵营调整兵种级数、编制比重或阵营级维度，使阵营点数等于预算、各兵种与各维度不越限
- [ ] 加预算、上下限、级数范围与比重之和的测试
- [ ] 重跑平衡统计并记录

## 开发者提示

- **可复用能力**：阵营定义里已有开局编制、各类据点的援军编成与两个倍率；阵营对冲与 AI 对 AI 整局的平衡统计。
- **开发要点**：
  - 地图是按种子生成的，各类据点的数量每局不同，标准据点组合取多种子的平均。
  - 现有四阵营里会有超出 −8…+16 的兵种（如武士），要在调平时收进范围，这一步会改变这些兵种的强度。
  - 阵营的特点描述与倍率写在产品文档里，改完同步。
