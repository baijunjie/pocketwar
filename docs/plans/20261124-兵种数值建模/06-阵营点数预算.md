# 阵营点数预算

> 目标: 四个阵营的阵营强度相等（这就是「各阵营点数相同」），平地循环赛过线；兵员数量纳入同一笔预算；级数范围与单兵种上下限从这里开始执行。
> 完成判据: 提交的循环赛结果表里，各阵营平均优势在 ±0.05 内、任一对阵在 ±0.15 内；提交的阵营实测表里，各阵营的阵营强度两两相差不超过 2 点；单元测试读这两张表断言上述门槛，并断言各兵种实测点数、各维度级数不越限、编制比重之和为 1，表过期时失败；兵员倍率只能由阵营的兵员级数给出。

依赖 [04-兵种表点数化.md](04-兵种表点数化.md) 的点数与越限清单、[05-兵力占用与编制.md](05-兵力占用与编制.md) 的兵力份数。

## 技术设计

- [ ] 阵营的标准军：300 份兵力 × 兵员倍率，按开局编制混编；对手是 300 份兵力的标准混编军
- [ ] 阵营强度 = 阵营测量量出的点数 + 战略维度的成本。战略维度指机动、射程、纪律，成本 = Σ 该兵种这三个维度的价目 × 高于基准的级数 ×（该兵种的兵力份数 ÷ 标准混编军里对应位置的兵力份数）；低于基准的级数不计成本，它的损失只由阵营测量体现。理由：这三样加级的好处在平地量不出，不计成本就能白堆；减级不能倒找点数
- [ ] 预算：现有四阵营阵营强度的中位数
- [ ] 两张提交的数据表，都带过期指纹：阵营实测表（各阵营的阵营测量结果、战略维度成本、阵营强度、标准误）、循环赛结果表（每组对阵的优势与各阵营的平均优势）
- [ ] 估算阵营点数 = Σ 兵种估算点数 ×（该兵种的兵力份数 ÷ 标准混编军里对应位置的兵力份数）。只用来在调数值时预览方向，不设门槛
- [ ] 兵员：阵营级维度，每级人数 ×1.035，级数可以取小数；它值几点由阵营测量直接给出，不另定价
- [ ] 援军倍率在本里程碑各阵营统一取 1（援军在 [07-整局校准.md](07-整局校准.md) 才调）
- [ ] 级数范围以 [04-兵种表点数化.md](04-兵种表点数化.md) 的初值表为准，只在一种情况下放宽：某个维度有超过两成的现有兵种越限，就放宽到全部现有兵种的八成落在范围内（去掉离得最远的），其余仍算越限
- [ ] 单兵种上下限约束的是实测点数：−2…+5
- [ ] 兵种数量与原型覆盖不作统一要求
- [ ] 初调（每一步之后重新量）：
  1. 把越限的兵种与维度收进范围
  2. 量阵营强度，与预算的差额用该阵营全军生命整体平移补：差几点就平移几级，取整
  3. 剩下不足一级的零头用兵员级数补：先量兵员加 1 级值几点，按比例取小数级
  4. 各阵营与预算相差不超过 0.5 点即完成初调
- [ ] 终调以平地循环赛为准，它比对标准混编军的强度更接近真实对局，所以优先：
  - 某阵营平均优势超出 ±0.05：按「0.045 优势约合 1 点」折算，用全军生命平移修正，重跑循环赛。修正后不再要求回到预算 ±0.5 点，只要求各阵营的阵营强度两两相差不超过 2 点；超过 2 点说明相性太强，找出该阵营偏差最大的那一组对阵，按下一条的做法处理
  - 某一组对阵超出 ±0.15 而双方平均优势都在线内：这是对阵相性。让占优一方逐个去掉自己的克制与受击修正特性重打这一组，找出让优势下降最多的那一条，把它的倍率向 1 收一半，重跑循环赛
  - 找不出这样的特性（相性来自原型的固定克制或编制）：让占优一方逐个把某个兵种换成所属位置的基准重打这一组，找出让优势下降最多的兵种，把它的编制比重降两成、均摊给其它兵种，重跑循环赛

## 开发者提示

- **可复用能力**：阵营定义里已有开局编制、各类据点的援军编成与两个倍率；测量工具的阵营测量、人数测量、兵种测量与循环赛。
- **开发要点**：
  - 原型实测现有四阵营差距很大：平地对冲里日本对每个阵营的优势都在 −0.22 以下，中国、罗马最强。调平的幅度会明显大于「微调」。
  - 对阵相性实测很强：300 人规模下波斯对日本 +0.22、对罗马 −0.24。终调大概率要动克制，而不只是动总量。
  - 胜负很果断：全军生命差 2 级胜率就到八成，所以循环赛按优势验收，不按胜率。
  - 全军生命平移改的是该阵营每个兵种的生命级数；平移后越出生命范围的兵种，把越出的部分改加到输出上。
  - 「全军生命平移 1 级 = 1 点」只在标准混编军上精确成立，各阵营编制不同会有出入，所以每一步之后都要重新量。
  - 现有援军倍率是中国 1.25、日本 1.07、罗马 0.94、波斯 1，统一取 1 会改变整局里的强弱，到 07 才重新调回各阵营各自的值。
  - 收进范围会改变越限兵种的特色（例如铁炮的节奏远超上限），这是有意的。
  - 阵营的特点描述与倍率写在产品文档里，改完同步。
