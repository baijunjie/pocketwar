# 兵种表点数化

> 目标: 兵种表从填绝对数值改为填「原型、各维度级数、特性」，面板由原型基准与阶梯算出，净点数由估值函数算出；现有 28 个兵种照实倒推成级数作为起点。
> 完成判据: 列入维度的属性在兵种表里都只填级数，由级数推出面板；不计点的字段与特性参数照原值保留；倒推后各兵种每个维度与改动前的偏差不超过一个步长，越出级数范围的不截断、列成清单；估值函数有单元测试（等比维度每级正好 1 点、护甲与节奏的点数随参考军变化的方向正确、超过 +6 级的加价）；AI 战力估值与经验值改由兵种价值（不含加价）给出；阵营对冲统计里各阵营的偏差不大于改动前，前后用同一种不依赖战力估值的战果度量。

依赖 [01-伤害公式改为强度对比式.md](01-伤害公式改为强度对比式.md) 的伤害公式与 [02-兵种类别改为原型.md](02-兵种类别改为原型.md) 的原型、标签与特性。

## 技术设计

- [ ] 原型基准面板：每个原型一份，净点数为 0；初值取该原型下现有兵种各维度的几何中位数，不带特性
- [ ] 原型声明开放哪些维度，并可以为维度声明自己的上下限；没声明的取下表的范围
- [ ] 维度阶梯（步长与范围是初值，由 [06-对战校准.md](06-对战校准.md) 修正）：

  | 维度 | 每级效果 | 点数 | 级数范围 |
  |---|---|---|---|
  | 生命 | ×1.05 | 每级 1 点 | −6…+12 |
  | 输出（每秒伤害） | 间隔 ÷1.05，单次伤害不变 | 每级 1 点 | −6…+12 |
  | 节奏 | 单次伤害与间隔同乘 1.15 | 估值函数算 | −8…+8 |
  | 近战护甲、远程护甲（各一维） | +1 | 估值函数算 | 0…+8 |
  | 机动 | 速度 ×1.03 | 每级 1 点 | −4…+6 |
  | 射程（远程类） | ×1.04 | 每级 1 点 | −4…+6 |
  | 纪律 | 士气基准 +2 | 每级 1 点 | −3…+6 |
  | 冲击（骑兵、载具） | 冲撞伤害 ×1.08 | 每级 1 点 | −3…+6 |
  | 治疗（神职，落地后启用） | 治疗量 ×1.05 | 每级 1 点 | −4…+8 |

- [ ] 标准混编军：各原型的基准单位按一张固定的原型比重表混编，初值取现有四阵营的平均人数比例，之后只在校准时更新；给出参考攻击（近战、远程、不计护甲三类的占比与各自的参考打击强度）、参考护甲分布、各标签的占比
- [ ] 估值函数：价值 = 有效生命 × 有效输出 × 修正项
  - 有效生命 = 生命 ÷ 在参考攻击下的平均承伤比例（护甲、举盾、龟甲阵、受击修正在这里起作用）
  - 有效输出 = 每秒伤害 × 对参考护甲分布的平均穿透比例 × 按标签占比加权的克制倍率（节奏、破甲、克制在这里起作用）
  - 修正项 = 机动、射程、纪律、冲击等按上表每级 ×1.05，加上其余特性的价目
- [ ] 净点数 = 以 1.05 为底、兵种价值与所属原型基准价值之比的对数，再加上加价
- [ ] 加价规则：每级 1 点的维度超过 +6 级后每级多收 1 点；维度可以降到基准以下换回点数
- [ ] 特性价目：举盾、破甲、克制、受击修正、龟甲阵由估值函数算；范围杀伤、副武器、武士道、立枪拒马、边走边射这类估值函数表达不了的按包定初价（由校准修正）
- [ ] 兵种定义：原型、各维度级数、特性清单
- [ ] 等级与高级形态仍是全兵种统一的倍率，不计入点数
- [ ] AI 战力估值 = 兵种价值的平方根 × 统一的缩放系数（不含加价），缩放系数取到与现有估值同量级；经验值仍由战力估值换算

## 实现方案

- [ ] 把对冲统计的战果度量改成不依赖战力估值的量（剩余人数比例），改动前先跑一次作基线
- [ ] 定六个原型的基准面板与标准混编军
- [ ] 写估值函数及其单元测试
- [ ] 写倒推工具：把现有每个兵种的面板换算成各维度最接近的级数，输出净点数与越限清单
- [ ] 兵种表改成级数与特性的写法，面板在展开兵种时由基准与阶梯算出
- [ ] 替换战力估值与经验值的来源
- [ ] 重跑对冲统计，与基线对照

## 开发者提示

- **可复用能力**：内容层「登记后统一展开」的兵种展开流程（现在在这里合并类别缺省值、生成高级形态、按等级展开数值）；阵营对冲统计。
- **开发要点**：
  - 现有战力估值是价值的平方根量级，士气的敌我战力对比、AI 的兵力判断和经验门槛都按这个量级调过；现有的对冲统计也用它算剩余战果，所以要先换度量再对照。
  - 生命有一个全局倍率（控制会战节奏），在展开时乘上，与点数无关。
  - 级数范围与单兵种上下限在本里程碑不执行，到 [05-阵营点数预算.md](05-阵营点数预算.md) 才执行。
  - 对建筑倍率、最近射程暂不计点（见 [README.md](README.md)「待定」），迁移时照原值保留。
  - 数值表以产品文档为准，改完同步。
