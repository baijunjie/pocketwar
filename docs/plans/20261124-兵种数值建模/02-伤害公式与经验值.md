# 伤害公式与经验值

> 目标: 单位与建筑受击都按强度对比式结算；被击杀时给出的经验值只看类别（原型落地后是原型），不随兵种强弱变。
> 完成判据: 单元测试覆盖新公式（破甲、克制倍率与对建筑倍率进入打击强度、溃兵不计护甲、雪天护甲减半、不计护甲的攻击、没有保底）与经验值规则；用测量工具跑阵营循环赛，改动前后各阵营平均优势的变化不超过 0.05；用测量工具量标尺（100 人、全军生命 −12 到 +12 级、每 2 级一个点、每点 48 个样本、沿用原型的种子表），与 [原型验证记录.md](原型验证记录.md)「标尺：全军生命的响应」的表对照，各点差异不超过 0.05；全部测试通过。

依赖 [01-对战测量工具.md](01-对战测量工具.md) 的循环赛。

## 技术设计

- [ ] 打击强度 d = 攻击 × 克制倍率；打建筑时 d = 攻击 × 对建筑倍率
- [ ] 伤害 = d × d ÷（d + c × 护甲 ×（1 − 破甲）），c = 2，作为规则数值登记；单位与建筑共用，不设保底
- [ ] 不计护甲的攻击（投石、火箭、火炮）按护甲 0 结算；火把打建筑仍按材质倍率，不走护甲
- [ ] 溃兵不计护甲并加倍率、雪天据点外护甲减半、据点升级的护甲加成：规则不变，作用在新公式的护甲项上
- [ ] 举盾、龟甲阵、林地、城墙垛口、等级防御这些后续倍率的顺序与数值不变
- [ ] 现有兵种与建筑的护甲数值沿用
- [ ] 经验值：被击杀时给出的经验只看类别，作为规则常量登记：步兵 16、枪兵 10、远程 8、骑兵 21、骑射 13、战象 41、器械 30（各类别基准单位的战力估值 × 10）；高级形态再乘统一倍率 1.3；不随兵种自身数值变
- [ ] 战力估值（士气与 AI 用）仍按兵种自身数值算，本里程碑不动

## 实现方案

- [ ] 改动前用测量工具跑一次阵营循环赛作基线
- [ ] 把单位受击与建筑受击的护甲结算换成同一个强度对比式
- [ ] 改经验值的来源
- [ ] 重跑循环赛，与基线对照

## 开发者提示

- **可复用能力**：测量工具的循环赛；内容层展开兵种时已经在算每个兵种的战力估值与经验值。
- **开发要点**：
  - 规则数值集中在内容层的规则表，系统里不写死数字。
  - 箭塔放箭、副武器、冲撞、立枪反伤、范围杀伤、践踏都走同一个单位受击结算。
  - 现在单位受击保底 1、建筑受击保底 1（远程 0.5），新公式恒为正。会碰到保底的只有单位受击；建筑受到的计护甲伤害只来自蝎弩和战象（人形单位打建筑是扔火把，不计护甲），都远在保底之上。
  - 原型实测两项一起改时，四阵营两两对冲的优势变化都在 0.05 以内（见 [原型验证记录.md](原型验证记录.md)「新伤害公式对阵营平衡的影响」）。
  - 高级形态的护甲 +2 与界面详情面板里的护甲数值含义随公式改变。
  - 规则与数值以产品文档为准，改完同步。
