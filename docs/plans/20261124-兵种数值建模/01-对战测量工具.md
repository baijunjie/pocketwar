# 对战测量工具

> 目标: 把原型里的对战实验做成项目里可重复使用的开发工具：给出两支军队，按固定规程量出谁强、强几点。后面每个里程碑的验收都用它。
> 完成判据: 同一组种子重复运行结果完全一致；在现有规则下跑阵营循环赛，与 [原型验证记录.md](原型验证记录.md)「新伤害公式对阵营平衡的影响」表里「现有规则」一列对照，用与原型相同的种子表，每组对阵的差异不超过两边标准误合成后的三倍；工具本身不被游戏运行时引用。

## 技术设计

- [ ] 测量规程（固定，不随调用方变）：
  - 场地：平地，关掉昼夜天气与迷雾；双方相距 1400，攻击移动到中点，每 10 秒让残部继续寻敌，最长 420 秒
  - 战果：双方剩余生命占开局的比例之差，叫「优势」
  - 样本：同一对阵换边各打一场取平均，算一个样本；报告均值与标准误
- [ ] 基准单位：每个原型一个，取该原型现有兵种各维度的几何中位数，不带兵种特有的特性；原型落地前按现有七个类别各取一个
- [ ] 维度阶梯的步长（按级数造变体用）：

  | 维度 | 每级效果 |
  |---|---|
  | 生命 | ×1.05 |
  | 输出 | 攻击间隔 ÷1.05，单次伤害不变 |
  | 节奏 | 单次伤害与间隔同乘 1.15 |
  | 近战护甲、远程护甲 | 各 +1 |
  | 机动 | 速度 ×1.03 |
  | 射程 | ×1.04 |
  | 纪律 | 士气基准 +2 |
  | 冲击 | 冲撞伤害 ×1.08 |
  | 治疗 | 治疗量 ×1.05 |

- [ ] 标准混编军：按固定的位置表混编基准单位，每 100 人是步兵 26、枪兵 22、远程 31、骑兵 12、骑射 5、器械 3、战象 1；位置表只在校准时显式更新
- [ ] 标尺：全军生命加减若干级对标准混编军的优势曲线
- [ ] 点数换算：让对手（标准混编军）全军生命 −6 级，使被测一方落在线性段；同一批种子再量被测一方全军生命 ±3 级，得到当地斜率；点数 = 优势的增量 ÷ 斜率
- [ ] 五种测量，括号里是缺省的规模与样本数：
  - 维度测量（100 人，48 个样本）：标准混编军里某个位置全员某维度加减若干级，值几点
  - 人数测量（300 人，96 个样本）：标准混编军里某个位置加若干人，值几点
  - 兵种测量（100 人，48 个样本）：标准混编军里某个位置整个换成某个兵种，值几点
  - 阵营测量（300 人，48 个样本）：某阵营的标准军对标准混编军，值几点
  - 循环赛（每方 300 人，每组对阵 24 个样本）：各阵营的标准军两两对冲，输出每组对阵的优势、各阵营的平均优势
- [ ] 阵营的标准军：按该阵营开局编制生成、含开局兵力倍率的一支军队
- [ ] 人少的位置（骑射、器械、战象）做维度测量与兵种测量时改用 300 人、96 个样本
- [ ] 结果不显著（增量的绝对值小于两倍标准误）时如实标注，由调用方决定怎么用
- [ ] 输出成表格文件，供后续里程碑生成实测表

## 实现方案

- [ ] 以原型脚本为起点整理成工具，对战与统计分开，五种测量共用同一个对战函数
- [ ] 支持多进程并行跑不同的对阵
- [ ] 加测试：确定性、小规模冒烟
- [ ] 在现有规则下跑阵营循环赛（沿用原型的种子表），与原型验证记录对照

## 开发者提示

- **可复用能力**：
  - 原型脚本在分支 `proto/unit-stat-model` 的 `proto/` 目录：基准单位、变体生成、平地对战、换边取样、军队描述的写法都已有，可以直接搬。
  - 测试里已有平地无头世界的辅助与阵营对冲统计；兵种登记表是可追加的数组，临时兵种追加进去即可参战。
- **开发要点**：
  - 100 对 100 一场约 0.37 秒；48 个样本约 36 秒，标准误约 0.01 优势、0.2 点。
  - 势均力敌附近优势对强弱极敏感（±2 级就到 ±0.15），不让级直接量会严重失真。
  - 原型里的标尺与各项实测都是在新伤害公式、经验值脱钩下做的，本里程碑还是现有规则，所以只对照阵营循环赛；标尺的对照放在 [02-伤害公式与经验值.md](02-伤害公式与经验值.md)。
  - 原型里为了切换伤害公式给规则表加过一个开关，那是实验用的，不要带进主干。
  - 「阵营的标准军」里的人数在 [05-兵力占用与编制.md](05-兵力占用与编制.md) 之后改按兵力份数算，届时本工具的规模参数也改成份数。
  - 现有测试里的阵营对冲每组只跑一个种子、用战力估值算战果，本工具替代它；旧统计在本里程碑保留，不删。
