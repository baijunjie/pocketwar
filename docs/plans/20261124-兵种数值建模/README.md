# 兵种数值建模

## 问题

- 兵种表直接填绝对数值，没有统一尺度回答「一个兵种值多少」「一个阵营整体是否高于另一个」；阵营强弱靠手调开局兵力倍率与援军倍率找平。
- 新文明、新兵种没有可复用的底盘：每个兵种都要从头定数值与行为。
- 实测现有四阵营在平地会战里并不平衡：中国、罗马明显强，日本每一组对阵都输（见 [原型验证记录.md](原型验证记录.md)「新伤害公式对阵营平衡的影响」）。

要做到的：先定几种基础单位，所有文明的兵种都在基础单位上调参数、换 3D 模型；每个文明用同样多的点数在各兵种能力上分配，形成特色，同时没有哪个文明的兵种整体高于别的文明。兵种多样性参考帝国时代 2。

## 方案概述

1. **规则**：伤害公式全游戏统一成强度对比式；经验值与兵种强弱脱钩。
2. **原型定底盘**：系统只认原型与标签，不认具体兵种。
3. **点数以实测为准**：1 点 = 标准混编军全军生命加 1 级。兵种和阵营值多少点，由对战测量工具量出来；另有一张分原型的价目表供调数值时即时估算。
4. **阵营预算**：兵力按兵力占用计；各阵营对标准混编军的实测强度相等，最后用循环赛验收。

方案的每个环节都在原型里跑过对战，数字与依据见 [原型验证记录.md](原型验证记录.md)。

## 关键设计决策

### 伤害公式

- 伤害 = d × d ÷（d + 2 × 护甲 ×（1 − 破甲）），d = 攻击 × 克制倍率（打建筑时乘对建筑倍率）。单位与建筑同一条公式，不设保底。
- 不照搬帝国时代 2 的减法（各攻击类别「攻击 − 护甲」求和、保底 1）。理由：减法会出现打不动的情况，帝国时代 2 靠玩家现造克制兵种来化解；本游戏的阵营编制是固定的，打不动就成了解不开的对阵劣势。
- 不用纯比例减伤。理由：重击和快击变得完全等价，「重击穿甲」这条兵种差异没了。
- 实测换公式并让经验值脱钩之后，四阵营之间的强弱几乎不变，现有护甲数值沿用。

### 经验值脱钩

- 被击杀时给出的经验值只看原型（高级形态按统一倍率），不再随兵种自身强弱变。
- 理由：现在兵种越强给对手的经验越多，而升一级攻防各 ×1.5，会在升级线附近造成跳变，实测出现过「骑兵输出加强后战果反而变差」。脱钩后兵种的价值才平滑、可度量。
- 战力估值（士气与 AI 用）仍随兵种强弱变，它的影响是平滑的。

### 原型与标签

- 七种原型：近战步兵、远程步兵、近战骑兵、远程骑兵、神职、载具、远程器械。
- 原型定四样：行为（近战或远程、能否边走边打、是否工程、是否治疗）、骨架与动画（各文明只换外观）、基准面板（即「基础单位」，点数 0）、开放哪些维度及各自的上下限。
- 与现有类别的对应：步兵与枪兵并入近战步兵，远程即远程步兵，骑兵即近战骑兵，骑射即远程骑兵，战象归载具（冲阵巨物，战车、冲车共用），器械即远程器械，神职是新增。
- 标签（借鉴帝国时代 2 的攻击类别 × 护甲类别）：每个兵种带原型标签和特性标签；克制是攻击方对带某个标签的目标的倍率，受击修正是防守方被带某个标签的攻击方打时的倍率（小于 1 是抗性，大于 1 是弱点）；命中的倍率全部相乘。
- 原型之间的固定克制（如骑兵打远程 ×1.4）留在原型上，全阵营一样；兵种特有的克制与受击修正是特性。
- 枪兵不再是类别，「长柄」成为特性：反骑、立枪拒马，同时仍被步兵克（×1.25）、仍让骑兵打它减伤（×0.8）、不吃载具对近战步兵的 ×1.2。理由：现有行为不变。

### 维度

- 兵种在原型基准上按等比阶梯调：生命、输出（只改攻击间隔）、节奏（单次伤害与间隔同乘）、近战护甲、远程护甲、机动、射程、纪律、冲击、治疗。
- 攻击不拆成「攻击」「攻速」。理由：连弩（6 / 0.6 秒）与铁炮（46 / 4.8 秒）每秒伤害几乎相同，差的只是节奏。
- 维度可以降到基准以下。理由：否则做不出「玻璃大炮」和「步兵单薄」。
- 等级和高级形态对所有兵种是同一套倍率，不计点。

### 点数

- 1 点 = 标准混编军全军生命加 1 级（×1.05）带来的战果变化；生命是一般等价物。
- 兵种点数 = 把标准混编军里它对应的位置整个换成它之后，全军相当于生命加了几级。它由对战量出来，包含全部特性的真实效果。
- 不用「价值 = 有效生命 × 有效输出」的公式给每个兵种算点数。理由：实测不成立——生命的价值取决于它占全军生命池的比例，输出的价值取决于实际打出去的伤害（器械与战象是面板的 5–7 倍，骑兵的普通攻击几乎为零、价值在冲锋上），远程兵种的护甲几乎无效。
- 调数值时用价目表即时估算：分位置、分维度的每级点数，由测量工具量出。估算用来指路，实测用来定论。
- 机动、射程、纪律在平地会战里量不出价值，但在整局里有用，它们的价格在整局对战里定；定出之前给一个不为零的地板价。

### 阵营预算

- 兵力按兵力占用计：每个原型一个占用值，开局兵力和援军都按兵力份数算，不再按人头。理由：实测日本的兵种并不弱，弱在编制里没有战象与骑射、器械很少，而这些原型每人的价值是步兵的几倍到十几倍；按人头计，缺高价值原型的阵营天然吃亏。
- 「各阵营点数相同」落成：各阵营的阵营强度相等。阵营强度 = 标准军对标准混编军的实测强度 + 机动、射程、纪律的成本。实测强度一次量进了兵种质量、编制比重与兵员人数，不需要再给每一项分别加权；机动、射程、纪律在平地量不出，所以按价目另算成本。
- 另有估算阵营点数（兵种估算点数按兵力份数加权求和），只用来在调数值时预览方向，不设门槛。理由：估算和实测总有出入，两个都当硬门槛时调平收敛不了。
- 兵员与援军数量是阵营级维度，多兵就得少质量：兵员体现在开局标准军的人数里，援军体现在援军标准军的人数里，都由实测强度约束。理由：保留「兵多 / 兵精」的阵营特色，又不让它游离在预算之外。
- 预算大小取现有四阵营阵营强度的中位数。
- 编制比重由阵营自定；兵种数量与原型覆盖不作统一要求。
- 现有兵种先照实倒推、不截断；级数范围与单兵种上下限到调平预算时才执行，越限的收回。
- 调平有固定做法：先把越限兵种收进范围，剩下的差额用「全军生命整体平移若干级」补齐（约每级 1 点，且不改变兵种之间的相对特色），不足一级的零头由兵员吸收；每一步之后重新量。
- 援军折进预算的办法：按整局统计出的据点出兵情况算出各阵营的预期援军编成，组成援军标准军，同样量它对标准混编军的强度，用援军人数把各阵营调平。理由：把高点数兵种集中放进援军的阵营，援军人数会被压低。

### 验收

越靠后的越接近真实对局，冲突时以后者为准：

1. 阵营强度：初调到各阵营与预算相差不超过 0.5 点；经后两道修正之后，只要求两两相差不超过 2 点。
2. 平地循环赛：各阵营的平均优势在 ±0.05 内、任一对阵在 ±0.15 内。
3. 整局循环赛：电脑对电脑，各阵营总胜率 40–60%。援军标准军的强度先初调到各阵营相等，经整局循环赛修正后只要求两两相差不超过 2 点。

各道门槛各有专用的调法，互不干扰：阵营强度与平地平均优势靠全军生命平移和兵员，对阵相性靠克制与编制，整局胜率只靠援军人数。

理由：克制关系带来的对阵相性很强（实测波斯对标准混编军很强，对罗马却大败），单一的强度数字只能保证「没有哪个文明整体更高」，两两之间要靠循环赛兜住。

## 待定

- **建筑的护甲、生命与攻击机制是否整体重做**：伤害公式已经统一，但这三样本身要不要重新设计尚未讨论；对建筑倍率、最近射程这类只影响攻城的属性怎么计点一并待定，迁移时照原值保留、不计点。
- **神职的治疗规则，载具里战车与冲车的行为**：尚未设计，对应里程碑未写；原型里神职暂不落地。
- **渲染侧「骨架与动画归原型、各文明只换外观」怎么落**：载具与远程器械下各兵种的骨架并不相同。本计划的里程碑不动渲染侧的模型与动画。
- **平地会战之外的情境**：实测都在平地对冲里做，攻城、守城、地形与天气下各维度值多少没有量过，目前只靠整局循环赛兜底。
