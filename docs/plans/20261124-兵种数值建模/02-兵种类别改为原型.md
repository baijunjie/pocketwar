# 兵种类别改为原型

> 目标: 模拟层用「原型 + 标签」取代现有的「类别」，枪兵并入近战步兵、长柄成为特性；玩法行为与改动前一致。
> 完成判据: 对照测试证明每个兵种的面板数值、对每个兵种的克制倍率、特殊动作与改动前逐项一致；系统代码只读原型、标签与特性，不出现具体兵种；全部测试通过。

## 技术设计

- [ ] 原型：行为（近战或远程、能否边走边打、是否工程、是否人形、是否治疗）、体型、对其它原型的固定克制、类别原有的缺省属性
- [ ] 落地六个原型，与现有类别的对应：

  | 原型 | 现有类别 | 原型自带 |
  |---|---|---|
  | 近战步兵 | 步兵、枪兵 | 火把 |
  | 远程步兵 | 远程 | |
  | 近战骑兵 | 骑兵 | 冲锋、火把 |
  | 远程骑兵 | 骑射 | 边走边射 |
  | 载具 | 战象 | |
  | 远程器械 | 器械 | |

- [ ] 神职暂不落地（原因见 [README.md](README.md)「待定」）
- [ ] 标签：每个兵种带所属原型的标签，特性可以再给它加标签（如长柄）
- [ ] 特性：挂在兵种上的命名能力，带自己的参数；其中克制是「打带某个标签的目标」的倍率，受击修正是「被带某个标签的攻击方打」的倍率（小于 1 是抗性，大于 1 是弱点）
- [ ] 倍率合成：攻击方对目标的倍率 = 原型固定克制 × 攻击方命中目标标签的各条克制 × 目标命中攻击方标签的各条受击修正，全部相乘
- [ ] 长柄特性：立枪拒马；克制近战骑兵、远程骑兵、载具（倍率是特性的参数，各枪兵可以不同），对长柄 ×0.8；受击修正为被近战步兵打 ×1.25、被近战骑兵打 ×0.8、被载具打 ÷1.2。合成后与现状一致：长柄互打 ×1，战象打长柄 ×1
- [ ] 原型的固定克制照现有类别表迁移；兵种特有的克制（僧兵对骑兵与骑射、投矛散兵对战象与骑兵、蝎弩对战象、各枪兵对骑兵的倍率差异）记在兵种的特性上
- [ ] 伤害结算与索敌优先级共用同一个「攻击方对目标」的克制查询

## 实现方案

- [ ] 先写对照测试：记录改动前每个兵种对每个兵种的克制倍率、面板数值与特殊动作，作为迁移后的比对基准
- [ ] 引入原型、标签与特性的登记，把现有七个类别迁成六个原型加特性
- [ ] 伤害结算与索敌改走统一的克制查询
- [ ] 界面上显示类别名的地方改显示原型名
- [ ] 对照测试通过后删除类别

## 开发者提示

- **可复用能力**：内容层已有类别、体型、兵种的登记函数与「登记后统一展开」的机制；特殊动作（冲锋、立枪、举盾、火把）与被动特性已按兵种携带的参数驱动。
- **开发要点**：
  - 倍率连乘会有浮点误差（如 1.2 ÷ 1.2），对照测试比较倍率时用近似相等。
  - 加兵种、调数值只动内容层，换算法只动系统层；系统里不认具体兵种。
  - 主菜单与游戏内界面都显示类别名，「枪兵」这个名称会消失，属于界面文案改动。
  - 规则以产品文档为准，改完同步。
