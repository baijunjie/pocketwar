# 阵营与兵种

四个阵营：中国、日本、罗马、波斯，各有 7 个兵种。兵种的通用规则（原型、克制、体型、等级、高级形态、特殊动作、点数机制）见
`docs/product/units.md`「兵种」与「点数机制」。

### 阵营点数与预算

阵营强弱按点数计账（1 点的含义与兵种点数见 `docs/product/units.md`「点数机制」），只看配置、不跑对战：

- **阵营点数** = Σ 兵力比重 × 兵种点数 + 兵员级数 × 1.4（兵员每级 1.4 点，加级减级同价）。
- **阵营预算 5.5**：固定的数，不随兵种、编制变化。每个阵营的阵营点数不超过它；各阵营用兵员级数补到预算（向下取到 0.01 级，差额不到 0.02 点）。
- **援军点数** = Σ 全兵种援军表的比重 × 兵种点数 + 援军级数 × 1.4，比重 = 份数 ÷ 每批总份数。
- **援军预算 5.5**：同样是固定的数。每个阵营的援军点数不超过它，援军级数取补到预算的级数（向下取到 0.01 级）。
- 配一个新阵营：定开局编制（比重之和为 1）与全兵种援军表；`npm run measure -- breakdown` 列出阵营点数、与预算的差额和补到预算要的兵员级数，
  `npm run measure -- reinf` 列出援军点数与补到预算要的援军级数（都是纯计算）。
  `npm run measure -- budget --write` 与 `npm run measure -- reinf --write` 按固定预算重算各阵营的兵员级数、援军级数并写回；
  兵种、维度单价、特性点数、编制或援军表变了都要重算，预算本身不动。
  编制比重由阵营自定，兵种数量与原型覆盖不作统一要求。

## 兵种数值

一级、初级形态的数值，攻击与间隔是主武器的。生命已乘全局倍率；速度是「奔跑 / 行军」；护甲是「近战 / 远程」；「最近」是器械的最近射程；
射程一栏近战写「近战」，攻击距离比贴身长的写成「近战 22」（攻击距离见 `docs/product/units.md`「武器」）；
点数是兵种点数（算法见 `docs/product/units.md`「兵种点数」）。
高级形态按 `docs/product/units.md`「高级形态」的倍率换算。

下面的人数是玩家一方（电脑一方按难度倍率，见 `docs/product/match.md`「电脑对手」）。
