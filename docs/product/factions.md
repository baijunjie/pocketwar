# 阵营与兵种

四个阵营：中国、日本、罗马、波斯，各有 7 个兵种。兵种的通用规则（原型、克制、体型、等级、高级形态、特殊动作、点数机制）见
`docs/product/units.md`「兵种」与「点数机制」。

### 阵营点数与预算

阵营强弱按点数计账（1 点的含义与兵种点数见 `docs/product/units.md`「点数机制」），只看配置、不跑对战：

- **阵营点数** = Σ 兵种点数 × 份数之比 + 兵员单价 × 兵员级数。
  - 份数之比 = 兵员倍率 × 该兵种的兵力比重 ÷ 标准混编军里它所在位置的兵力比重，即两边人数之比。直射器械的位置顶替器械位，
    按「器械位的人数比例 × 直射器械的兵力占用」算它在标准混编军里的兵力比重。
  - 机动、射程、纪律（战略维度）已含在兵种点数里：只按高于基准的级数计，低于基准的不计、不退点（见 `docs/product/units.md`「点数机制」）。
  - 兵员单价由价目表给出（每级约 0.9 点，加级减级同价）。
- **阵营预算 3.317**：现有四阵营在迁移前的兵员级数（中国 1.69、日本 −2.11、罗马 −1.95、波斯 −1.19）下阵营点数的中位数。每个阵营的阵营点数不超过它；现有四阵营用兵员级数补到预算（向下取到 0.01 级，差额不到 0.02 点）。
- **援军点数**：算法与阵营点数相同，编制换成全兵种援军表（比重 = 份数 ÷ 每批总份数），兵员倍率与兵员级数换成援军倍率与援军级数，
  单价与兵员级数共用。
- **援军预算 6.862**：现有阵营援军点数（援军级数按 0）的中位数。每个阵营的援军点数不超过它，援军级数取补到预算的级数（向下取到 0.01）。
- 配一个新阵营：定开局编制（比重之和为 1）与全兵种援军表；`npm run measure -- breakdown` 列出阵营点数、与预算的差额和补到预算要的兵员级数；
  `npm run measure -- budget --write` 与 `npm run measure -- reinf --write` 重算两个预算与各阵营的兵员级数、援军级数并写回（价目表、兵种、编制、援军表或阵营增减变了都要重算）。
  编制比重由阵营自定，兵种数量与原型覆盖不作统一要求。

## 兵种数值

一级、初级形态的数值。生命已乘全局倍率；速度是「奔跑 / 行军」；护甲是「近战 / 远程」；「最近」是器械的最近射程；
点数是兵种点数（`npm run measure -- breakdown` 的当前值，价目表重量后会变）。
高级形态按 `docs/product/units.md`「高级形态」的倍率换算。

下面的人数是玩家一方（电脑一方按难度倍率，见 `docs/product/match.md`「电脑对手」）。

- **城池与城镇**共用每个阵营的一张全兵种援军表，倍率是阵营的援军倍率，城镇再 ×0.6：两者编成一致，区别只在规模。
