# 攻城与城防

建筑分哪几种角色、防御建筑怎么放箭、建筑怎么被打、城墙怎么守。据点的类别、构成、占领与修复见 `docs/product/sites.md`「据点」。

## 建筑角色

据点里的每座建筑属于下面三种角色之一：

- **军事建筑**：会放箭的建筑——城池的角楼（3 级炮楼）与主堡，营寨的哨塔（3 级连弩哨塔）与中军帐，资源点自建的哨塔。
  可以被攻击；占领据点前必须全部摧毁（见 `docs/product/sites.md`「占领」）。
- **城防**：城墙、门楼、木栅、营门。只挡路、不放箭；可以被攻击（石墙只有工程类单位能破坏，见「攻打建筑」），占领时不用拆。
- **普通建筑**：民居、兵营、营帐，以及资源点的中央建筑（谷仓、伐木棚、采石棚、矿洞）。
  **不可被攻击**：不能对它下攻击命令（右键它等于右键地面），单位自动索敌、电脑选目标都不会挑它，投射物与范围伤害也不伤它。
  理由：拆了没有意义，还会把单位吸引过去做无意义的攻击。
- 例外：临时据点的行营可以被攻击，打掉它就摧毁了这座临时据点。

## 防御建筑

- **军事建筑会放箭**（射程 / 单支伤害 / 间隔 / 每轮支数）：
  - 角楼 290 / 24 / 0.9 秒 / 2 支；主堡的射程、单支伤害、间隔与角楼相同，每轮 4 支（相当于 2 座角楼）。
  - 哨塔 250 / 18 / 1.1 秒 / 1 支；中军帐的射程、单支伤害、间隔与哨塔相同，每轮 2 支（相当于 2 座哨塔）。
  - 资源点自建的哨塔 250 / 18 / 1.1 秒 / 1 支。
  - 门楼、营门不放箭。
- 每轮的几支箭各射一个敌人，由近及远，射程里的敌人不够时余下的都射最近那个。
- **中立据点的军事建筑同样放箭**，敌我双方都打（离得近的先挨），不受视野限制。
- 倒塌后正在重建的军事建筑修满之前不放箭（见 `docs/product/sites.md`「休整与修复」）。它们都能被摧毁。
- 据点升级后的火力（含 3 级的炮弹与连弩）见 `docs/product/sites.md`「据点升级」，资源点的哨塔见 `docs/product/sites.md`「资源点」。

## 攻打建筑

- **人形单位**（近战步兵、远程步兵、近战骑兵、远程骑兵）打建筑时改为**投掷火把**：在 60 的距离上出手，
  每 2.2 秒一支，伤害 16（每级 +50%）。火把不看护甲，按材质算：木质建筑 ×1.5，石质建筑 ×0.5，石质的门楼与角楼 ×0.3。
- **工程类单位**（抛射器械、直射器械、载具）照常用自己的攻击打建筑，伤害按 `docs/product/combat.md`「伤害」的强度对比式，
  d = 攻击 × 对建筑倍率（不乘克制倍率），护甲用建筑的：战象用近战护甲，直射器械（蝎弩，穿刺伤害）用远程护甲，抛射器械不计护甲；
  破甲对建筑不起作用，不设保底。对建筑倍率见 `docs/product/factions.md`「兵种数值」。抛射器械打敌兵时，落点上的敌方建筑一并受伤；
  打建筑时，落点周围的敌兵也受范围伤害。
- **城防工事**（石墙）火把烧不动，人形单位的任何攻击都无效，只有**工程类单位**（抛射器械、直射器械、载具）能破坏。
  石墙两格厚，要砸穿里外两格才有通路。对城防工事下达攻击命令时，人形单位会原地不动；选中的部队里没有工程类单位时，界面会提示。
- **中立建筑**：中立的军事建筑和敌方建筑一样，直接右键就能攻打，自动索敌也会打它。
  理由：它会主动放箭，又必须拆光才能占领，要特殊按键才能打就成了陷阱。
  中立的城防要 **Ctrl+右键**才会攻打；所选部队里有器械或战象时，中立的石墙、门楼直接右键就砸。
- 所以：营寨的木栅、营门、哨塔、中军帐可以直接烧；城池要么用器械砸开城墙，要么让士兵顶着箭慢慢烧毁门楼或角楼。
  城里的主堡不是城防工事，烧得动；民居、兵营不可被攻击。
- 桥是地形的一部分，不能破坏。

## 驻守城墙

- 石墙两格厚。墙顶上朝城外的那一圈格子是站位，**每格三人**（两人沿墙并排在前，一人在后；角楼顶上三格共九人）。
- **只有远程步兵**（步行的弓、弩手；远程骑兵不行）能上墙，而且是**自动的**：在自家城池的据点范围内待命的远程步兵
  各自走到最近的空站位下面、登上去，在那里坚守；站位满了，剩下的人留在地上。没有手动登城的命令。
  正在迎击（有目标、在走动）的远程守军不会上墙，回到待命后才登城。营寨的木栅不能上人。
- **墙上的守军会自己挪动**：没在射击、而警戒距离（560）内最近的敌人在射程（含城墙加成）的 95% 之外时，
  沿墙顶走到离那个敌人最近的空站位（至少近 48 才挪）。只在同一段连通的墙顶上走（门楼把墙分成几段）；
  这一段上没有更近的空位、而隔着门楼的另一段上有近得多的（至少近 200），就下墙、从城里绕过去、再登上那一段。
  沿墙走动时不射击。
- 站在垛口上的单位：射程 ×1.15，所受远程伤害 ×0.5，不会被冲锋撞到；地面上的近战单位够不着他们；别人挤不动他们。
- 给墙上的单位下任何别的命令（移动、攻击、停止），它会先走下城墙再照办，垛口随即空出来；「坚守」则留在原位。
  溃逃时同样先下墙。脚下的墙被毁、或据点易主时就地解除驻守。走到城里的新位置待命后，又会自动登城。
- 普通的移动命令点在墙顶上，落点会改到最近的地面；墙外的单位无论如何上不了墙。门楼顶上不能站人。
- 电脑一方开局城池的守备队开局就让弓弩手登城；守备队出击时，垛口上的人留在城墙上。
