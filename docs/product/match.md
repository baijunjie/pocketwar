# 对局

一局怎么开、在什么样的地图上打、对手怎么动、怎么分胜负。

## 概述

单机的千人会战即时战略，在桌面浏览器里运行。不建造、不造兵、不用派人采集：开局即拥有一整支军队，
调兵遣将、争夺据点与资源点，占领据点后定时得到援军，攻占敌方全部的城池与营寨取胜。对手是电脑；也可以观战，看电脑对电脑。

## 开局设置

主菜单里选好以下几项，点「开战」：

| 项 | 取值 | 缺省 |
|---|---|---|
| 阵营 | 中国、日本、罗马、波斯（卡片上有阵营介绍与兵种一览，见 `docs/product/factions.md`「阵营」） | 中国 |
| 对手 | 随机，或指定四个阵营之一（可以与自己同阵营） | 随机 |
| 每方兵力 | 425、850、1400、2100（兵力份数，见下） | 850 |
| 难度 | 简单、普通、困难（见「电脑对手」） | 普通 |
| 战争迷雾 | 开、关 | 开 |
| 模式 | 亲自指挥、观战（见 `docs/product/controls.md`「观战模式」） | 亲自指挥 |
| 地图种子 | 数字，「换一张」随机换；同一种子生成同一张地图 | 每次打开菜单随机 |

除地图种子外，这些设置会记住，下次打开菜单时沿用。

**每方兵力**按兵力份数计：1 份是一个近战步兵的兵力，别的兵种每人占几份由所属原型的兵力占用定（见 `docs/product/units.md`「原型」），
骑兵、抛射器械、战象每人占得多，同样的份数下这些兵种多的阵营人少。开局人数还要乘阵营的兵员倍率，850 份时各阵营约 520～620 人，
各档人数见 `docs/product/factions.md`「开局编制」。「每方兵力」的标签悬停可看这段说明的大意。

## 地图

- 程序生成，320×320 格。地形有草地、林地、丘陵、山、河流（深水、浅滩）、道路、桥、农田；山与深水走不过去，
  每条河有几处浅滩可以涉水，道路过河处架桥（地形对速度的影响见 `docs/product/movement.md`「地形与速度」）。
- 双方的据点**中心对称**地分布：玩家的开局城池在左下角，电脑的在右上角。每方各有：一座城池（名为「阵营名 + 都城」，
  如「中国都城」，类型、尺寸与地图正中的城池相同）与一座营寨，开局即归己方；以及中立的城镇、五座营寨、
  农庄、伐木场、采石场与两座金矿；地图正中是一座中立的城池。
  全图合计：城池 3、城镇 2、营寨 12、农庄 2、伐木场 2、采石场 2、金矿 4。
  各类据点的构成见 `docs/product/sites.md`「据点类别」。

## 开局部署

- 开局双方都是整编部队，全部是初级形态、新兵。兵种构成见 `docs/product/factions.md`「开局编制」。
- 玩家：约 8% 的部队在自家营寨，其余在出发阵地；开局城池没有守军。玩家开局不设集结点。
- 电脑：约 8% 在自家营寨，约 16% 守开局城池（弓弩手开局即登城），其余分成三路在出发阵地；各据点的集结点都设在出发阵地，
  援军先集结、凑够一队再派出去。

## 电脑对手

- 电脑把部队编成若干战斗群，争夺据点、回防，时机成熟后总攻敌方的城池与营寨（各战斗群挑离自己最近的一座）。
- 攻占据点时先拆军事建筑（中立的也一样），再肃清守军、站到旗下读秒。
- 撤退与回防以离该战斗群最近的己方城池为锚点，没有城池时用最近的营寨。
- 难度的影响：

| | 简单 | 普通 | 困难 |
|---|---|---|---|
| 电脑开局兵力 | ×0.8 | ×1 | ×1.2 |
| 电脑援军人数 | ×0.8 | ×1 | ×1.25 |
| 重新判断形势的间隔 | 2.5 秒 | 1.5 秒 | 1 秒 |
| 发起总攻：总战力达到玩家的几倍（或已没有可抢的据点） | 1.6 倍 | 1.25 倍 | 1.05 倍 |
| 最迟何时发起总攻 | 开局 15 分钟 | 10 分钟 | 7 分钟 |

- 电脑占下营寨时、以及每出一批援军后，给营寨选下一批出什么兵种：选在场兵力占比（按兵力份数算，本方别的营寨已选、还没出的一批也算）低于开局编制比重最多的兵种，
  让全军的兵种构成向本文明的开局编制回归，见 `docs/product/sites.md`「援军」。
- 电脑也花资源（见 `docs/product/economy.md`「资源」）。电脑不会扎营，也不会专门去拆玩家的临时据点。
- 电脑做战略判断时不受战争迷雾和夜晚影响（单位层面的索敌照样受视野限制）；它不会主动熄火把，也不会专门夜袭。
- 观战时双方都按「普通」难度指挥，兵力相同。

## 胜负

一方的城池与营寨（城池、城镇、营寨）全部丢失即判负，对方获胜；资源点和临时据点不算，
只要还剩一座城池或营寨就不算输。城池与营寨不会被摧毁，只会被攻占。结算画面见 `docs/product/controls.md`「结算」。
