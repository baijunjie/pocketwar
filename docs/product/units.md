# 兵种规则

兵种的通用规则：原型、克制、体型、等级、高级形态、特殊动作、兵种特性，以及配置兵种与阵营所依据的点数机制。
各阵营具体有哪些兵种、各自的数值见 `docs/product/factions.md`「兵种数值」。

## 兵种

每个兵种由「原型 + 各维度相对原型基准的级数 + 特性」定义：原型给出行为、体型、兵力占用与基准面板，
级数在基准面板上调出兵种自己的面板（见「点数机制」），特性加上标签、克制与特殊能力（见「兵种特性」）。
另有几项不计点的属性由兵种直接填：对建筑倍率、最近射程、投射物、视野。

### 原型

| 原型 | 体型 | 出手 | 兵力占用 | 被击杀经验 | 自带的特殊动作与特性 | 人形 / 工程 |
|---|---|---|---|---|---|---|
| 近战步兵 | 小 | 近战，站定出手 | 1 | 12 | 火把；举盾级数大于 0 的会举盾 | 人形 |
| 远程步兵 | 小 | 远程，站定出手 | 0.76 | 8 | — | 人形 |
| 近战骑兵 | 中 | 近战，边走边打 | 3.75 | 21 | 冲锋、火把 | 人形 |
| 远程骑兵 | 中 | 远程，边走边打 | 1.5 | 13 | 边走边射 | 人形 |
| 载具 | 巨 | 近战，站定出手 | 6.3 | 41 | 践踏 | 工程 |
| 抛射器械 | 大 | 远程，站定出手，抛射落点 | 6.4 | 30 | — | 工程 |
| 直射器械 | 大 | 远程，站定出手，直射追踪 | 1 | 26 | — | 工程 |

- 现有兵种里，战象是载具；投石、火炮、火箭车是抛射器械，蝎弩是直射器械。
- 器械按武器体系分两个原型：抛射器械打攻城伤害（不计护甲），投射物飞向预判的落点、带范围杀伤；
  直射器械打穿刺伤害（按远程攻击结算），投射物追踪目标、单体杀伤，目标在飞行途中死了就落空。
- **兵力占用**：每人占几份兵力，近战步兵为 1。开局兵力与援军都按兵力份数计，人数 = 份数 ÷ 兵力占用
  （见 `docs/product/match.md`「开局设置」与 `docs/product/factions.md`「援军编成」）。
- **人形**单位打建筑时投掷火把，**工程**类用自己的攻击打建筑并能破坏石墙（见 `docs/product/siege.md`「攻打建筑」）。
- 界面上的兵种类型写原型名，带标签的特性跟在后面，如「近战步兵·长柄」。

### 克制

- 每个兵种带若干**标签**：自己的原型，加上特性给的标签（目前只有「长柄」）。
- **克制**是攻击方打带某个标签的目标时的倍率，**受击修正**是目标被带某个标签的攻击方打时的倍率（小于 1 是抗性，大于 1 是弱点）。
- **克制倍率** = 攻击方的克制里目标命中的各条 × 目标的受击修正里攻击方命中的各条，命中的全部相乘，没有命中为 1。
- 原型固定的克制，全阵营一样：近战骑兵打远程步兵 ×1.4、打抛射器械与直射器械 ×2；载具打近战骑兵、远程骑兵 ×1.5，打近战步兵 ×1.2。
  特性给的克制与受击修正见「兵种特性」；兵种用某个特性时可以改写其中某一条的倍率。
- 例：近战步兵打长柄 ×1.25，近战骑兵打长柄 ×0.8，长柄打长柄 0.8 × 1.25 = 1，载具打长柄 1.2 ÷ 1.2 = 1。
- 克制倍率乘在攻击上进伤害公式（见 `docs/product/combat.md`「伤害」），挑目标时也看它（见 `docs/product/combat.md`「战斗寻敌」）。

### 体型

体型越大越慢、越吃粮、近战时能同时围上来的敌人越多。

| 体型 | 碰撞半径 | 速度倍率 | 口粮（份/分钟） | 最多被几人围攻 | 林中速度 |
|---|---|---|---|---|---|
| 小型 | 6 | ×1.0 | 1 | 3 | ×1.0 |
| 中型 | 9 | ×0.9 | 2 | 4 | ×0.75 |
| 大型 | 12 | ×0.8 | 2 | 5 | ×1.0 |
| 巨型 | 15 | ×0.7 | 4 | 6 | ×1.0 |

实际奔跑速度 = 基准机动（原型基准按机动级数调过的）× 体型的速度倍率。

### 等级与经验

- 击杀敌人得到该敌人的全部经验值，最近 6 秒内打过它的另外两人各得 40%（助攻）。
  经验值只看原型（见「原型」的被击杀经验），与兵种自身强弱无关；高级形态 ×1.3（取整）。
- 共 5 级（界面上记作 1～5 级）：新兵、老兵、精锐、悍卒、宿将，所需累计经验 0 / 30 / 80 / 160 / 300。
- 每升一级：攻击 +50%，防御 +50%（受到的伤害除以 1 + 0.5 × 级数），士气基准 +4；生命、护甲、攻击间隔、**移动速度不变**。
  也就是 5 级（宿将）攻击 ×3、防御 ×3（2 级 ×1.5、3 级 ×2、4 级 ×2.5）。火把伤害同样按攻击加成。升级时当场士气 +10。
- 等级越高越不容易溃逃（见 `docs/product/morale.md`「士气与溃逃」）。头顶的金色小点表示等级（1 级没有，5 级四个点）；
  只选中一个单位时，兵种栏上方的详情面板列出它的等级、经验进度和各项数值的等级加成（见 `docs/product/controls.md`「详情面板」）。

### 高级形态

每个兵种都有初级、高级两个形态，开局和援军都是初级。高级形态要花**黄金**升级（见 `docs/product/economy.md`「资源」）：

- 生命 ×1.35，攻击 ×1.25，近战与远程护甲各 +2；速度、射程、口粮、特殊动作不变。等级与经验照旧保留，
  升级时按原来的伤势比例换算生命。
- 花费 = 口粮份数 × 10 黄金：小型（近战步兵、远程步兵）10，中型（近战骑兵、远程骑兵）与大型（抛射器械、直射器械）20，巨型（战象）40。
- 名称是「重甲 + 原名」（器械是「包铁 + 原名」，另有个别单独起名的：重装骑兵、具装铁骑）。
  外观上换成全身甲：胸背甲、甲裙、臂甲、腿甲、护颈、重盔，披一件队伍色的披风；马披全身马甲，器械包铁并加挡板，战象披甲。
- **升级次序**：等级高的优先；同一等级里各兵种轮流，每轮每个兵种升一人，直到全部升完或黄金用尽
  （这一个升不起就跳过，后面便宜的兵种还升得起就接着升）。
- 界面：选中的部队里有能升级的、黄金至少够升一人时，指令面板的「升级」一栏出现「升级所选部队」；黄金至少够在**全图**的己方部队里
  升一人时，另外出现「部队全部升级」：按上面的次序升，直到全部升完或黄金用尽（按钮上写「能升几人 / 一共几人」）。

### 特殊动作

进入战斗状态时自动触发，不需要操作。

- **冲锋**（近战骑兵）：隔着至少 90 的距离发现敌人时发起，速度 ×1.3，最长 5 秒。冲到跟前时撞上的敌人受到
  冲撞伤害（即冲击：铁骑、骑马武者 135，罗马骑兵 125，铁甲骑兵 157.5），照常乘克制倍率、按近战护甲折算；
  撞上新兵弓弩手一下就倒，撞上新兵刀盾兵也去掉约七成的血。一次冲锋最多撞 3 人。冷却 8 秒。
  接到「移动」「坚守」命令时不会冲锋。站在城墙上的单位撞不到。
- **立枪拒马**（带「长柄」的）：附近（约 190）有敌人冲锋过来时立枪 2.5 秒，期间自己几乎不动（速度 ×0.15）。
  冲锋的骑兵撞上立着的枪：冲撞伤害无效、冲锋中止、停顿 0.8 秒，并受到 60 × 克制倍率的反伤（照常按护甲折算）。
- **举盾**（近战步兵里举盾级数大于 0 的：刀盾兵 60%、军团步兵 70%、辅助矛兵 55%、持盾矛兵 65%、不死军 55%）：
  看到附近有远程敌人，或者挨了远程攻击，就举盾 6 秒：移动速度 ×0.8，远程伤害按括号里的比例减免。正在近战肉搏时腾不出手举盾。
  与龟甲阵叠乘。
- **火把**（近战步兵、近战骑兵）：见 `docs/product/environment.md`「视野、昼夜与天气」。

### 兵种特性

挂在兵种上的命名能力：

| 特性 | 兵种 | 效果 |
|---|---|---|
| 长柄 | 长戟兵、足轻枪兵、辅助矛兵、持盾矛兵 | 带「长柄」标签；立枪拒马。克制近战骑兵 ×2.4（长戟兵、足轻枪兵 ×2.5）、远程骑兵 ×2、载具 ×2，打长柄 ×0.8；受击修正：被近战步兵打 ×1.25，被近战骑兵打 ×0.8，被载具打 ÷1.2 |
| 薙刀 | 僧兵 | 克制近战骑兵 ×1.6、远程骑兵 ×1.4 |
| 标枪 | 投矛散兵 | 克制载具 ×2.5、近战骑兵 ×1.3 |
| 重弩 | 蝎弩 | 克制载具 ×2 |
| 穿刺攻击 | 目前没有兵种用 | 抛射器械的攻击改按远程攻击结算：减远程护甲，吃举盾、龟甲阵、林地、垛口的减免（抛射器械本来的攻城伤害不计护甲，也不吃这些减免；直射器械本来就是穿刺伤害） |
| 重标枪 | 军团步兵 | 副武器：伤害 26、射程 95、间隔 14 秒 |
| 副弓 | 不死军 | 副武器：伤害 7、射程 170、间隔 2.4 秒 |
| 武士道 | 武士、骑马武者 | 伤害 ×（1 + 0.5 × 已损失的生命比例），血越少打得越狠；扔火把打建筑时不算 |
| 龟甲阵 | 军团步兵 | 所受远程伤害常驻 −35% |
| 践踏 | 载具自带 | 近战攻击打的是以目标为中心、半径 28 的一片敌人，离中心越远伤害越低（边缘为中心的 40%） |

- **副武器**：接敌途中够得着就先用副武器出手，按远程攻击结算，伤害不随等级加成。

- **最近射程**：器械打不了贴得太近的敌人（数值见 `docs/product/factions.md`「兵种数值」），不计点。

## 点数机制

点数是兵种与阵营强弱的统一尺度，新兵种、新阵营都按它配置：兵种在原型基准上加减维度级数、挂上特性，按价目表计出兵种点数；
阵营的点数与预算见 `docs/product/factions.md`「阵营」；点数的实测依据、估算的边界与尚未覆盖的情境见 `docs/unit-stat-model.md`。

- **1 点** = 标准混编军全军生命加 1 级（×1.05）带来的战果变化。
- **标准混编军**由各位置的基准单位组成，人数比例：近战步兵 26%、近战步兵（长柄）22%、远程步兵 31%、近战骑兵 12%、
  远程骑兵 5%、抛射器械 3%、载具 1%。
- **位置**：价目按位置分。七个原型各是一个位置，带「长柄」的近战步兵另算一个（它的基准 = 近战步兵基准 + 长柄）。
  直射器械的位置不进标准混编军，**顶替**器械那 3% 的人数：它的价目与兵种点数在「标准混编军的抛射器械整个换成直射器械基准」的军队上量，
  参照组也是这支军队，所以直射器械基准同样是 0 点；两种器械每人价值的差别由兵力占用体现。

### 原型基准面板

基准单位是点数 0 的兵种。一级、初级形态的数值，生命已乘全局倍率，护甲是「近战 / 远程」，速度是体型折算后的奔跑速度；
纪律、破甲、举盾都是 0。

| 原型 | 生命 | 攻击 | 间隔（秒） | 射程 | 护甲 | 速度 | 其它 |
|---|---|---|---|---|---|---|---|
| 近战步兵 | 172 | 9 | 1.2 | 近战 | 2 / 3 | 58 | |
| 远程步兵 | 92 | 9 | 1.9 | 235 | 0 / 0 | 58 | |
| 近战骑兵 | 330 | 15 | 1.27 | 近战 | 3 / 2 | 105 | 冲击 135 |
| 远程骑兵 | 209 | 9 | 1.8 | 195 | 1 / 1 | 118 | |
| 载具 | 1012 | 28 | 2.0 | 近战 | 3 / 4 | 62 | |
| 抛射器械 | 330 | 53.5 | 7.5 | 425 | 0 / 0 | 28 | 范围 30；攻城伤害；最近射程缺省 100 |
| 直射器械 | 220 | 90 | 4.5 | 400 | 0 / 0 | 34 | 穿刺伤害；最近射程缺省 60 |

`npm run measure -- base` 打印各位置的基准面板。

### 维度与级数

兵种只能在原型开放的维度上加减级数，级数要在范围内，算出的护甲不得低于 0。

| 维度 | 每级 | 开放给 | 级数范围 |
|---|---|---|---|
| 生命 | 生命 ×1.05 | 全部原型 | −6…+12 |
| 输出 | 攻击间隔 ÷1.05，单次伤害不变 | 全部原型 | −6…+12 |
| 节奏 | 单次伤害与攻击间隔同 ×1.15，每秒伤害不变 | 全部原型 | −8…+8 |
| 近战护甲 | +1 | 全部原型 | −3…+8 |
| 远程护甲 | +1 | 全部原型 | −3…+8 |
| 机动 | 基准机动 ×1.03 | 全部原型 | −4…+6 |
| 纪律 | 士气基准 +2 | 全部原型 | −3…+6 |
| 射程 | 射程 ×1.04（取整） | 远程步兵、远程骑兵、抛射器械、直射器械 | −6…+6 |
| 冲击 | 冲撞伤害 ×1.08 | 近战骑兵 | −3…+6 |
| 破甲 | +10%：攻击时无视目标这一比例的护甲 | 远程步兵、抛射器械、直射器械 | 0…+8 |
| 范围杀伤 | 半径 +2：落点周围半径内的敌人都受伤，离落点越远越低（边缘为中心的 40%），不伤自己人 | 抛射器械 | −15…+5（半径 0…40） |
| 举盾 | 举盾减免 +5%，大于 0 才会举盾 | 近战步兵 | 0…+14 |

等级与高级形态对所有兵种是同一套倍率，不计点；对建筑倍率、最近射程、投射物、体型、视野也不计点。

### 兵种点数

- **兵种点数** = Σ 各维度级数 × 价目表里该位置、该维度的单价 + 兵种自己的特性的价目。
  每格单价分加级与减级两个，减级按负的级数乘减级单价；原型自带、位置基准本来就带的特性不另计。
  机动、射程、纪律（战略维度）只计高于基准的级数（× 加级单价），低于基准的不计、不退点：加级的好处在平地量不出、不计就能白堆，减级的损失只在整局里。
- 单兵种点数要在 **−2…+5** 之内。
- **价目表**：每个位置、每个开放维度一格，含义是「该位置全员加（减）1 级值几点」；特性的价目是位置基准带上它与不带它之差。
  都由对战测量工具实测，统计上不显著的记 0；加级单价实测为负的按 0（加一级不能倒找点数），减级单价为负的照记（减一级反而更强，减级时是收点数）。
  机动、射程、纪律在平地会战里量不出价值，加级单价取实测值与同位置生命加级单价的 1/3 中较大的一个。
- 价目表随原型基准、特性、规则数值与测量规程而定，这些变了价目表就过期（单元测试会失败），要重量：
  `npm run measure -- prices`（全部重量，中断后加 `--resume` 接着量）；兵员级数的单价单独用 `npm run measure -- manpower` 量；
  只改了汇总规则或地板价、测量没变时用 `npm run measure -- prices --derive` 按已有测量重新汇总（只重写价目表；测量本身过期时报错，要先重量）。
  兵种用到的维度或特性在价目表里没有条目时直接报错（不按 0 计），要先把那一格量出来。
- 查看：`npm run measure -- breakdown` 列出各阵营每个兵种的点数；`npm run measure -- units` 量全部兵种的实测点数，
  `npm run measure -- report` 列出估算与实测相差超过 1 点的兵种。实测只作参考，用来发现估算的偏差（叠加极端的兵种估算会偏），不作门槛。
- **战力估值**（士气与电脑判断形势用）：原型基准单位的估值（生命与每秒伤害之积的平方根，远程 ×1.15，带范围杀伤 ×1.6），
  按兵种点数折算：点数折成「生命与输出各加几级」（÷ 该位置生命与输出的加级单价之和），每级 ×1.05；高级形态再 ×√(1.35 × 1.25)。
