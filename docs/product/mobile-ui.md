# 移动版界面

触屏手机竖屏时用的界面与手指操作。没写到的规则（选择与指令的效果、各面板的内容、卡片代表哪些人、小地图上画什么）与桌面版相同，
见 `docs/product/controls.md`；本文只写移动版不同的地方。

## 启用

- 右上角「设置」里的「界面」：**自动**（默认）/ **桌面** / **移动**，会记住（设置面板见 `docs/product/controls.md`「设置面板」）。
- **自动**：主要指针是触屏且竖屏时用移动版，其余用桌面版；对局中转成横屏即回到桌面版，转回竖屏再切回移动版。
- **桌面** / **移动**：不管设备与方向，一律用所选的一套。电脑上选「移动」也能用，鼠标左键当作手指。
- 切换时收起抽屉与菜单，正在进行的手指手势作废。

## 布局

屏幕上下各半：

- **上半屏**：游戏画面。
  - 顶端一条细顶栏：双方现存人数、对局用时、粮（存粮与每分钟净收支）、木 / 石 / 金；最右是「菜单」按钮。
    桌面版顶栏里的时辰与天气、风向、士气、帧率不显示。
  - 指令模式的提示条在顶栏下方，占满宽度；战报紧接在下面（没有提示条时就在顶栏下方），最多同时 3 条，内容同桌面版。
  - 详情面板（选中一个单位，或没选部队而选着一个据点时）浮在上半屏底部、紧贴分屏线，左右让出两侧的把手；
    最高约占屏幕的四分之一，超出可在面板内滚动。自己营寨的兵种按钮排成一行，横向滑动。
  - 左右边缘中部各有一个把手，分别拉出据点列表与指令面板（见「抽屉」）。
- **下半屏**：
  - 顶部紧贴分屏线是卡片带（见「卡片带」）。
  - 其下是放大的圆形小地图，在剩下的空间里按短边放到最大（见「小地图」）。

按钮都放大到手指好点的尺寸。

## 菜单

点顶栏最右的「菜单」弹出一组按钮：暂停 / 1× / 2× / 4×、全屏、音效、设置、帮助、退出，作用同桌面版右上角的按钮组
（见 `docs/product/controls.md`「速度、帮助与退出」）。点其中任一个按钮后菜单收起；再点「菜单」或点菜单以外的地方也收起。
「设置」弹出的设置面板在顶栏下方右侧，只有「界面」一行（见「移动版不做的」）。

## 遮罩

抽屉、菜单、设置面板任何一个开着时，画面上盖一层半透明遮罩。点遮罩（即点它们以外的地方）只把它们全部收起，
这一下不落到画面上，不选择也不下令。

## 抽屉

据点列表与指令面板平时收在屏幕两侧，用时滑出：**据点列表在左，指令面板在右**，各占上半屏（顶栏以下到分屏线）、约屏宽的八成（最宽 320 像素）。
同一时间只开一个。

- **拉出**：在把手上往屏幕里滑，或点一下把手。
- **收起**：在抽屉上往回滑（据点列表往左、指令面板往右），或点抽屉以外的地方（见「遮罩」）。
  在抽屉里滑动不会点中滑过的按钮。
- **据点列表**：内容同桌面版（见 `docs/product/controls.md`「据点列表」），始终展开、不能收起；列表可上下滑动。
  点一行（或一个资源点小牌子，手指没怎么动就抬起才算点）：镜头跳过去并选中这个据点，同时收起抽屉。
- **指令面板**：按钮同桌面版（见 `docs/product/controls.md`「指令面板」），不显示快捷键。点部队、援军栏的指令按钮后抽屉收起；
  「升级」一栏的按钮点了不收起。另有移动版专有的**取消选择**按钮：取消选中的部队与据点，同时退出指令模式；
  既没选部队也没选据点时变灰。

## 画面上的手指操作

只在上半屏的画面上起作用。手指按下后移动不超过 10 像素仍算没动。

- **点一下**：
  - 处于指令模式时，在那里执行（规则同桌面版左键执行，见 `docs/product/controls.md`「指令」）。
  - 点在己方单位上：选中它；0.35 秒内连点两下同一兵种的单位，选中屏幕内这个兵种的全部己方单位。
  - 选着部队时点在别处：照桌面版右键处理——点地面移动，点（看得见的）敌军攻击它，点敌方建筑或中立的军事建筑攻打它；
    点在据点上是把部队派过去（可以占领），不会选中据点。中立的城防不能这样强攻（桌面版要 Ctrl+右键），带着器械或战象时中立的城墙、门楼照样直接砸。
  - 没选部队时：点据点选中它（规则同桌面版左键点据点），点空地取消选择（部队与据点）。
- **长按**（按住不动约 0.5 秒）：选着部队时，攻击移动到那里（规则同桌面版 F + 左键，按在敌方建筑上则直接攻打它）；支持的设备上轻振一下。
  没选部队、或处于指令模式时不响应。
- **单指拖动**：框选，框住的己方单位替换当前选择。框只在上半屏的画面里，手指拖进下半屏时框停在分屏线；不像桌面版那样合并卡片。
  处于指令模式时拖动不框选，什么也不做。
- **双指**：捏合缩放、拧转旋转视角，都以两指中点为中心；两指一起移动是平移，两指按住的那块地面跟着手指走。
  手势不调俯角。双指平移会取消镜头跟随，只缩放、旋转不取消。
  双指之后，直到手指全部抬起，剩下的那根手指不再当作点、长按或框选。
- 处于指令模式时，再点一次对应的指令按钮退出；「取消选择」也退出。提示条上写着怎么操作。

## 卡片带

下半屏顶部一条，编队卡片在前、兵种卡片在后（兵种卡片最前是全选卡片，约 60 像素宽），排成一行；卡片比桌面版略小。
卡片代表哪些人、卡片上显示什么同桌面版（见 `docs/product/controls.md`「兵种栏」「全选卡片」「编队卡片」）。

- **点**卡片、**连点两下**：同桌面版的点击、双击（没有 Shift 加选）。
- 按住卡片后手指移出约 8 像素时按方向定性，一次按住只定一次：
  - **竖直方向为主**：拖卡片下令。卡片缩小画在手指上方；松在上半屏的画面或小地图上，落点按手指位置，规则同桌面版拖卡片下令
    （见 `docs/product/controls.md`「指令」）；松在其它界面上即取消，卡片在那里变灰。
  - **水平方向为主**：左右滚动卡片带，不选择。
- 按在卡片之间的空隙上只能滚动卡片带；按在变暗（禁用）的全选卡片上也一样，只能滚动。

## 小地图

下半屏卡片带以下，圆形，显示内容与旋转规则同桌面版（见 `docs/product/controls.md`「小地图」）。

- **单指滑动**：移动镜头，手指所在处始终在画面中央。**点一下**：镜头跳过去。都会取消镜头跟随。
- 处于指令模式时，点一下在那一点执行。
- 没有桌面版右键的对应操作。

## 帮助

内容同桌面版（见 `docs/product/controls.md`「速度、帮助与退出」），其中操作表换成触屏操作：点选、单指框选、
点地面 / 敌人 / 据点下令、长按攻击移动、双指缩放旋转、拖动小地图、竖着拖卡片下令、两侧把手。桌面版的键鼠操作表
（含「详细操作与规则」里的键位表）不显示，规则说明照常显示。

界面上的提示文字（指令模式提示、战报、详情面板与卡片带里的提示）在移动版里不提键位与鼠标键，改说对应的触屏操作。

## 移动版不做的

- 没有贴边卷屏与出界续卷，也没有锁定鼠标：设置面板里「滚轮 / 双指」「锁定鼠标」两行不显示。
  锁定鼠标在移动版里始终关闭，切回桌面版时按设置里记住的开关恢复。
- 据点列表不能收起（桌面版的 L 与标题栏折叠）。
- 没有触屏手势对应的操作：加选、右键拖动列阵、调俯角。
