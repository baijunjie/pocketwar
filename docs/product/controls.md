# 操作与界面

玩家怎么操作（鼠标、键盘）以及对局里各块界面显示什么、能点什么。指令的效果（编队行军、攻击移动、坚守等）见
`docs/product/movement.md`「行军与队列」与 `docs/product/combat.md`「战斗」。Mac 上 Ctrl 与 Cmd 等效。
本文写的是桌面版（键鼠操作）；触屏手机竖屏时的移动版界面与手指操作见 `docs/product/mobile-ui.md`，两者用哪套见那里的「启用」节。

## 选择

- **左键点击**己方单位选中它；**拖框**选中框内的己方单位。按住 Shift 点击是加选 / 去掉这一个，按住 Shift 拖框是加选。
- 从画面上拉的框扫到底部的卡片时，扫到的兵种卡片（这张卡代表的人，见「兵种栏」）、编队卡片（这一队，见「编队卡片」）
  与框住的单位合并成一次选择，按住 Shift 同样是加选；拖动中被框扫到的卡片高亮。
- **双击**一个单位：选中屏幕内同一兵种的全部己方单位。
- 溃逃中的单位不能被选中，选着的单位溃逃了会自动从选择里去掉；敌军、中立单位不能选。
- **左键点据点**（点在它的建筑上，或点在旗帜圈里）：没点到己方单位时选中这个据点（敌方、中立的也能选，用来查看），
  兵种栏上方显示据点详情；自己的城池、营寨可以在那里升级，自己的资源点可以建哨塔。右侧据点列表里点一行也能选中，同时镜头跳过去。
  还没探索到的地方的据点点不中。选部队即取消选中据点。
- **Ctrl+A**（或指令面板「全军」）：选中全图的己方部队。
- **Esc**：依次是关掉帮助、收起设置面板、退出当前的指令模式、取消选择（部队和据点）。锁定鼠标时 Esc 先交给谁见「锁定鼠标」。

## 指令

都作用于当前选中的部队。

- **右键地面**：移动（编队行军，自动列阵：近战在前、远程居后、器械殿后）。
- **右键按住拖动**：在按下处列阵，面朝拖动的方向（原地拖动即原地转向重排）；拖动时地上画出朝向箭头。
- **右键敌军**（要看得见）：攻击它。**右键敌方建筑**或**中立的军事建筑**：攻打它。
  中立的城防（城墙、门楼、木栅、营门）要 **Ctrl+右键**才会攻打；带着器械或战象时，中立的城墙、门楼直接右键就砸。
  普通建筑不可被攻击，右键它等于右键地面（见 `docs/product/siege.md`「建筑角色」）。
  对石墙下令而选中的部队里没有器械或战象时，不下令，只提示打不动。
- **F + 左键**：攻击移动，沿途遇敌即战、见敌方建筑就打，遇墙自动破城；点在敌方建筑（或中立的军事建筑）上则直接攻打它。
- **X**：停止；**H**：坚守（见 `docs/product/combat.md`「待命与坚守」）。
- **T**：所选部队里只要有人点着火把就全部熄灭，否则全部点燃（入夜且不下雨时才真正点着，见
  `docs/product/environment.md`「视野、昼夜与天气」）。
- **B + 左键**：扎营，派所选部队到指定位置搭一座临时据点（见 `docs/product/sites.md`「临时据点」）。木材不够时按 B 只提示。
- **R + 左键**：设置援军集结点（每个据点各有一个，只对之后新出的援军有效，见 `docs/product/sites.md`「援军」）：
  选中己方据点时只设这个据点的；没选据点时给当时全部的己方据点设同一点。不需要先选部队；选部队即取消选中据点，所以选着部队时按 R 是给全部据点设。
  **Shift + R**：取消集结点，新出的援军留在据点里：选中己方据点时只取消它的，没选据点时全部取消。
  只有会出援军的据点（城池、城镇、营寨）能设集结点，资源点与临时据点不能。
  选中的是敌方或中立据点时，R 与 Shift + R 都不响应，只提示「只能给己方据点设集结点」；选中己方的资源点或临时据点时同样不响应，提示「这个据点不出援军」。
  理由：按「没选据点」处理会意外改掉全部据点的集结点。
- F、B、R 按下后进入对应的**指令模式**：画面上的鼠标指针变成十字准星（见「鼠标指针」），顶栏下方居中的提示条写出下一步怎么点；左键（在地面或小地图上）执行，
  右键或 Esc 退出，再按一次同一个键也退出。
- **拖卡片下令**：在兵种卡片或编队卡片上按住拖动（移动约 6 像素以上才算拖动，否则按点击处理），卡片缩小跟在鼠标右下方。
  松在画面或小地图上：选择换成这张卡代表的人（兵种卡片见「兵种栏」，编队卡片是这一队），并攻击移动到松开处，规则同 F + 左键
  （松在敌方建筑上则直接攻打它）；处于指令模式时同时退出指令模式。
  鼠标移到其它界面上时卡片变灰，在那里松开即取消；拖动中按右键、按 Esc、窗口失去焦点也都取消。
  取消时选择不变，这一下右键不当作右键下令，这一下 Esc 也只取消拖动、不往下传（不退出指令模式、不取消选择）。
- 下令时地上插一个令旗标记（移动绿色、攻击红色），并有一声号令提示音；下不了的命令响一声拒绝音。

## 编队

- **Ctrl+数字** 或 **Alt+数字**：把当前选中的部队编为该队（覆盖原来的）。
- **数字**：选中该队（已阵亡、溃逃的不算）；0.4 秒内连按两次同一个数字，镜头跳到这队的重心。
- **Shift+数字**：追加编队，把当前选中的部队并入该队，并选中合并后的整队。
- 编组、追加后兵种栏上方立即出现或更新这一队的卡片（见「编队卡片」）。

## 镜头

- **移动**：W A S D / 方向键、点或拖动小地图、鼠标贴边卷屏与出界续卷、触控板双指滑动（见下）。
- **贴边卷屏**：鼠标贴到屏幕最外沿（离边 6 像素以内）即卷屏，底下压着界面面板也照卷；离边 6 像素以外不卷。
  按着鼠标键拖动时不卷（画面上拖框、拖卡片、拖动小地图、右键拖动列阵、中键拖动），帮助打开时、窗口没有焦点时也不卷。
- **出界续卷**：鼠标从某条边离开网页（比如冲进浏览器的标签栏、macOS 全屏时碰出菜单栏）后，镜头朝那个方向继续卷，
  直到鼠标回到网页或窗口失去焦点。算作「从这条边离开」的：离开前最后的位置离这条边 6 像素以内，
  或离边 64 像素以内且最后一次移动正朝着这条边。横竖两个方向都算时，只有从角上离开（两个方向都在 6 像素以内）才斜着卷，
  否则只朝离边更近的那个方向卷。都不算的（比如从屏幕中间切到别的窗口）不续卷；按着鼠标键拖出网页的也不续卷。
- **缩放**：鼠标滚轮或触控板捏合，以鼠标所指的位置为中心；按住 PageUp / PageDown（Mac 上 fn + ↑ / ↓）以屏幕中央为中心缩放。
  滚轮与捏合只在画面上起作用：在界面面板上捏合既不缩放镜头也不缩放网页，滚轮照常滚动面板里的内容。
- **触控板双指滑动**：平移镜头，像滚动网页一样画面跟着手指走；按住 Option（Alt）双指滑动则左右转、上下调俯角。
- **滚轮与双指的识别**：右上角「设置」里的「滚轮 / 双指」决定滚动事件当作鼠标滚轮（缩放）还是触控板双指滑动（平移）：
  「鼠标」「触控板」一律按所选处理；「自动」（默认）按事件特征判断，一串连续的滚动（含惯性）按头一个事件定性，
  中途出现触控板的特征就改判为触控板、不再改回。判断不准时手动选另外两项。捏合不受这项影响，总是缩放。
- **旋转**：中键拖动左右转、上下调整俯角；Q / E 左右转。**Shift+中键拖动**平移。**Home**（或 Backspace）复位朝向与俯角。
- **跟随（C）**：镜头平滑地跟着所选部队的重心走（跟的是按下时选中的那批人），指令面板「跟随」按钮同样开关、跟随中高亮。
  再按一次、或手动移动镜头（贴边卷屏、出界续卷、W A S D / 方向键、触控板双指平移、拖动平移、点小地图、连按编队号跳转）即取消；
  缩放（滚轮、捏合、PageUp / PageDown）不取消，跟随时缩放不往鼠标处挪。跟随的人全部阵亡时自动取消并提示。
- 开局镜头对着己方的出发阵地；观战时对着地图中央、拉得较远。

## 锁定鼠标

在「设置面板」里开启（默认关）。光标出不了画面，甩到屏幕边上就贴边卷屏，不会碰到浏览器的标签栏或系统菜单栏。

- 开启后在画面上左键点一下进入锁定，这一下不算选择。锁定中系统光标隐藏，由游戏画光标，样子与平时的鼠标指针相同（见「鼠标指针」）；
  光标推到边上就停在最外沿，一直贴边卷屏。
- 锁定中界面照常可点、可拖动、可悬停，悬停约 0.5 秒显示提示框（内容同平时的悬停提示）。
- **Esc**：全屏时（Chrome / Edge），锁定中按 Esc 照常交给游戏（顺序见「选择」），长按 Esc 才退出锁定；
  其他浏览器与非全屏时，第一下 Esc 只解锁，游戏收不到这一下。在设置里关掉锁定鼠标时立即解锁。解锁后再在画面上点一下即重新锁定。
- 浏览器拒绝锁定时战报提示再点一下画面；连续 3 次失败后这一局点画面不再进入锁定，并提示在设置里关掉再打开即可重试。

## 速度、帮助与退出

- **空格**（或 P）暂停 / 继续；**+ / −** 在 1×、2×、4× 之间调速。右上角也有「暂停 / 1× / 2× / 4×」按钮。暂停时仍可选择与下令。
- **F1**（或 ?）、右上角「帮助」可打开操作说明，说明打开期间游戏暂停。亲自指挥时，开局先显示胜利目标和选兵、移动、攻击、镜头操作。
  可展开「详细操作与规则」查看更多。内容超出面板时可在面板内滚动，底部的「开始指挥」按钮始终可见。
- **M**、右上角「音效」：开 / 关音效，设置会记住。右上角另有「全屏」、「设置」（见「设置面板」）与「退出」（回到主菜单）。
  右上角按钮组从左到右：暂停 / 1× / 2× / 4×、全屏、音效、设置、帮助、退出。浏览器不支持全屏时（如 iPhone 的 Safari）不显示「全屏」。

## 设置面板

点右上角「设置」弹出，再点一次收起，打开时按钮高亮。

- **滚轮 / 双指**：自动 / 触控板 / 鼠标，默认自动（各项含义见「镜头」）。
- **锁定鼠标**：开 / 关，默认关，附操作说明（见「锁定鼠标」）。浏览器不支持锁定指针（如 iOS Safari）时这一行不显示。
- **界面**：自动 / 桌面 / 移动，默认自动，决定用桌面版还是移动版（见 `docs/product/mobile-ui.md`「启用」）。
- 三项都会记住。点面板以外的地方、按 Esc、打开帮助、对局结束时收起面板。

## 鼠标指针

- 游戏里（含主菜单）的鼠标指针一律是一把剑，热点在剑尖；按钮、卡片、小地图、带悬停提示的文字上也是剑，不变成手形或问号。
- F / B / R 指令模式中，画面上是十字准星；界面面板与小地图上仍是剑。
- 文本框（主菜单的地图种子）保留输入光标。
- 锁定鼠标时游戏自己画的光标同样是剑，指令模式时在画面上是十字准星。

## 界面布局

各面板贴着屏幕边缘：左上是顶栏，右上是按钮组（见「速度、帮助与退出」），右侧一列从上到下是据点列表与指令面板，
左下是小地图，底部中央是兵种栏、其上方一排编队卡片（详情面板浮在最上方）；指令模式的提示条在顶栏下方居中，战报在提示条下方。
面板贴边的一侧留出的空白比卷屏区宽，鼠标顶到最外沿卷屏时不会压在按钮上（卷屏见「镜头」）。
窗口窄时顶栏只压缩末尾的调试文字（帧率等），不会伸到右上的按钮组下面。

## 顶栏

从左到右：双方阵营与现存人数；对局用时；时辰（清晨、上午、正午、下午、黄昏、夜晚）与天气（晴、雨、雪）；
有风时的风向标（见 `docs/product/environment.md`「视野、昼夜与天气」）；粮草（存粮与每分钟净收支，入不敷出、断粮时变色）；
木 / 石 / 金的存量；全军平均士气与正在溃逃的人数；帧率。
各项悬停可看细节：时辰天气的各项倍率、每种资源的每分钟收入与用处、粮草的产耗与粮仓上限、士气的各项加减。

## 据点列表

右侧上方列出全图的据点，己方的在前、中立其次、敌方最后（据点的位置与归属对双方始终公开）。

- 标题栏「据点与援军」点一下（或按 **L**）收起 / 展开列表，收起时只留标题栏；收起与否会记住。
- 每行：归属色点、名称（城池、营寨的名字后面用「★n」标示等级，n 为 1～3）、状态——己方的写距下一批的倒计时与产粮（营寨前面还有所选的兵种名；
  城池、城镇出全兵种援军，不再重复写），兵力已满时写「兵力已满」，中央建筑被毁时写「援军暂停」；中立的只写「中立」，敌占的写「敌占」（敌占营寨再加它此刻选的兵种）；临时据点写「休整」。
  右栏很窄，状态都写得很短，名字放不下时末尾用省略号；把鼠标悬停在行上，看这一行的全文（据点类别、出什么援军、暂停的原因、产粮）。
  正在被读秒占领时有进度条。
- 资源点挤成一排小牌子：一个字写产什么（粮 / 木 / 石 / 金），角上是哨塔数，悬停看归属；正在被占领时有进度条。
- 点一行（或一个小牌子）：镜头跳过去并选中这个据点。

## 兵种栏

画面底部中央一排兵种卡片：屏幕内（以及选着但已不在屏幕内）的每个己方兵种一张，按默认队列的前后排序。
卡片直接浮在画面上、没有外框，约 88 像素宽、头像 64 像素；左端是一个独立的暗底小块写人数。
卡片之间的空隙与左端小块都不挡鼠标，在那里点击、拉框就是在画面上操作（见「选择」）。

- 一张兵种卡片**代表的人**：屏幕内这个兵种，连同已选着但不在屏幕内的同兵种。点击、拖卡片下令、画面上拉框扫到卡片都按这个范围。
- 卡片上：头像、屏幕内的人数、兵种名、平均等级、平均血量条；选中了这个兵种的卡片上前一步并标「选 N」。高级形态的卡片样式不同。
  悬停看兵种数值与这批人的等级、士气。
- 左端小块：选着部队时写「已选 N」与平均士气（士气偏低时变色），没选时写屏幕内总人数与「拖去下令」。
- **点击**卡片：选中这张卡代表的人。**Shift（或 Ctrl）+点击**：这个兵种选着就全部去掉，没选就加选这张卡代表的人。**双击**：选中全图的这个兵种。
- **按住拖动**：拖卡片下令（见「指令」）。
- 屏幕内没有己方部队、也没选着部队时，这一排只显示操作提示。

## 编队卡片

兵种栏上方另起一排，玩家的每个还有活人（能操控的）的编队一张，按队号从小到大排；没有这样的编队时这一排不出现。
编组、追加编队后立即出现或更新；队里的人全部阵亡或溃逃后卡片消失。编队本身的操作见「编队」。

- 卡片上：左上角队号、人数、人数最多的兵种的头像与名字（不止一个兵种时名字后加「等」）、平均血量条；比兵种卡片略小。
  整队都在选择里时卡片上前一步。悬停看这一队各兵种的人数。
- **点击**：选中这一队（同按数字键）。**双击**：镜头再跳到这一队的重心（同连按两次数字键）。
- **按住拖动**：拖卡片下令（见「指令」），出动的是这一队。

## 详情面板

只选中一个单位、或没选部队而选着一个据点时，浮在底部卡片（兵种栏与编队卡片）上方。

- **单位**：头像、兵种、兵种类型（如「近战步兵·长柄」）与体型、初级（及升级要多少黄金）还是高级形态；等级、经验进度；生命、攻击、间隔、射程、
  护甲、防御倍率、行军与奔跑速度、士气与溃逃阈值（宿将写「死战不退」）、当前状态（行军 / 战斗、冲锋、立枪、举盾、城墙上、火把），
  以及冲锋、拒马、举盾、副武器、可破城墙、光环（光环名与加成的增减百分比，如「盾墙掩护 −20%」）等特长。带等级加成的数值标出加成。
  攻击、间隔、射程是主武器的：主武器带范围杀伤的（抛射器械、战象）攻击后面标「（范围）」；射程一栏远程写数值，近战写「近战」，
  攻击距离比贴身长的写成「近战 22」（见 `docs/product/units.md`「武器」）。悬停兵种卡片、营寨兵种按钮与主菜单兵种看到的兵种数值同样这么写。
  悬停面板看兵种说明，带光环的兵种在说明里写出光环的半径与加成（规则见 `docs/product/units.md`「光环」）。光环范围不在地上画出。
- **据点**：名称（带等级星数）、类别、归属；**状态**（交战中还是平静，原因与还要几秒平静，见 `docs/product/sites.md`「休整与修复」；
  资源点写明没有恢复能力）；建筑完好数、重建中的数量与总生命；城池、营寨的**等级**（n / 3 级，3 级写明解锁了什么——按据点里建筑的 3 级升级列出炮弹、连弩，悬停看这一级的加成）；
  守备（几处放箭或「不设防」，占领需几秒或「不能占领，只能摧毁」）；每分钟产出；出什么援军、间隔，或用途；
  己方出援军的据点还有**集结点**一行（已设，或未设、援军留在据点里）。营寨的「援军」一行写所选兵种与每批人数（如「长戟兵 × 12」）；中央建筑被毁时这一行末尾写「暂停：中央建筑被毁」。
  不是自己的、还有军事建筑立着的据点提示「要先摧毁全部军事建筑才能占领」及还剩几座；中立且有放箭的据点提示它会向双方放箭、可以直接右键攻击；
  不是自己的城池、营寨提示占领后可以升级（中立的营寨还加上「选择出哪个兵种」，合成一行）。
  自己的营寨下方有一排本文明全部兵种的头像按钮（含器械与战象）：所选的高亮，每个按钮写着此刻每批的人数，悬停看兵种说明；点一下改选，
  改选后援军计时从头开始（规则见 `docs/product/sites.md`「援军」）。
  自己的城池、营寨有「升到 n 级」按钮（写下一级的花费，悬停看下一级的加成与 3 级解锁的能力；满级时写「已升到最高级」），
  自己的资源点有「建哨塔 n / 4」按钮；资源不够时按钮变灰并写出现有多少。
  升级、建哨塔、全部升级这些按钮防连击：连续的第二下起不响应（双击只升一级）；改选兵种不受此限。

## 指令面板

右侧下方，分三栏：

- **部队**：攻击移动（F）、停止（X）、坚守（H）、火把（T）、扎营（B）、跟随（C）、全军（Ctrl+A）。没选部队时除「全军」外都变灰
  （「跟随」在跟随中仍可点，用来取消）。
- **援军**：集结点（R）、取消集结（⇧R）。「取消集结」在没有可取消的集结点时变灰：选中己方据点时看它自己，没选据点时看全部己方据点；
  选中敌方、中立或不出援军的据点时不变灰（按下只给提示）。
- **升级**：有能点的按钮才出现——「升级所选部队」「部队全部升级」「城池全部升级」「营寨全部升级」，按钮上写能升几个 / 一共几个与花费
  （规则见 `docs/product/units.md`「高级形态」与 `docs/product/sites.md`「据点升级」）。

## 战报

屏幕上方居中、指令模式提示条下方的消息条，最多同时 5 条，几秒后淡出。报的是：占领与失守（占下营寨时写出它出什么兵）、临时据点落成 / 作罢 / 被毁、营寨改选兵种、援军抵达（是否开赴集结点）、
我军或（看得见的）敌军成批溃逃（3 人以上）、入夜与天亮、下雨 / 下雪 / 雨雪停、断粮与恢复供应、升级结果、编队与跟随的变化、
命令下不了的原因。带地点的消息点一下镜头就跳过去。

## 小地图

左下角，圆形，跟着镜头旋转（屏幕的「上」就是小地图的「上」）。

- 显示地形、建筑（按归属上色）、战争迷雾、单位（敌军只显示看得见的）、全部据点（城池方块、营寨菱形、资源点与临时据点圆点）、
  当前镜头的视野框。
- 己方行进中的部队到目的地有一条流动的虚线（绿：移动；红：攻击移动、攻击）。编队画一条，不在编队里的按目的地归堆画。
- 占领据点时在那里闪一圈占领方的颜色，己方援军抵达时闪一圈白色。
- 右上角（圆外的空角）画风向：箭头指向风吹去的方向，风越大越长越亮；无风不画。
- **左键点 / 拖动**：移动镜头；在指令模式里左键则在那一点执行。**右键**：所选部队移动到那里（指令模式中右键是退出）。
  点圆外的空角也会换算到地图上对应的位置。

## 场景内的标记

- 选中的单位脚下一圈绿环；单位头顶：受伤的有血条（己方绿、敌方红；选中 40 人以内时选中的都显示），等级的金色小点，溃兵的小白旗。
  镜头拉得很远时不显示血条和等级点。
- 据点：旗下的白色小圈与旗帜、名牌（城池、营寨带等级星数，下有归属色与读秒进度）。资源点地上常驻一圈归属色的占领圈，
  临时据点常驻一圈休整范围；城池、营寨地上不画圈，围墙本身就是边界（据点范围见 `docs/product/sites.md`「据点范围」）。
  选中的据点：有围墙的沿围墙外沿画一圈跳动的虚线矩形，其余外围一圈亮环；资源点还空着的哨塔位是地上的黄圈。
  读秒占领时，占领方颜色的进度从旗下的小圈向外扩到整个据点范围（矩形或圈）。
  重建中的防御建筑头顶有划掉的箭头。建筑挨打后几秒内显示血条。
- 集结点：选中己方出援军的据点时显示它的集结点，一面队伍色的旗和一圈黄环；不选据点时不显示。

## 音效

全部由程序现场合成，没有音频文件：刀剑相击、放箭、抛射、中箭、火器开火、爆炸与巨石落地、骑兵冲撞、倒地、建筑垮塌、
火把砸中、升级钟音，以及下令与拒绝的提示音；环境声有风声（只在刮风时）和雨声。

- 战斗声按离镜头的远近定音量、按在屏幕上的左右定声像，镜头拉远整体变轻；同一种声音在很短的时间里只响一声（事件越多越响），
  千人混战也不会炸成一片。
- 浏览器要求先有一次点击或按键才能出声。

## 观战模式

开局设置里选「观战」：双方都由电脑指挥，战争迷雾关闭，不能选择或下令；指令面板与兵种栏只显示「观战模式」的提示，
不显示开局的操作说明。镜头、调速、设置、收起据点列表照常可用。

## 结算

一方的城池与营寨全部丢失即结束（见 `docs/product/match.md`「胜负」），弹出结算：胜利 / 战败并写明哪一方的城池与营寨已全部丢失（观战时写哪方获胜），双方的歼敌、损失、
其中逃散、援军、残存人数与用时，点「返回主菜单」回到主菜单。
