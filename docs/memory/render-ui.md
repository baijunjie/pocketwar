# 渲染与界面开发

- three.js 锁在 0.170.x（`package.json` 的 `^0.170.0`）。升级时要逐条核对 `src/render/materials.ts`、`src/render/terrain.ts`
  里着色器补丁 `replace` 的片段名（`#include <begin_vertex>` 等）：片段名一变，替换静默落空，不报错。
- 渲染要提速先看面数：骑兵连人带马是面数大户（马 2400–2600 个三角形，披全身甲的 2700–3200，再加骑手约 1800），先从它下手。
- 兵种的移动动作在对局里按「里程 ÷ stride」推进，与素材时长无关：只在预览页看动作会漏掉对局里的步频问题（马的慢步曾因此在对局里成了碎步）。做或验收移动动作要在真实对局里看，规则见 `docs/unit-art-spec.md` 的 `stride`。
