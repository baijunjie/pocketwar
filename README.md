# 烽烟

浏览器里的千人会战即时战略。不造兵、不用派人采集：开局即拥有整支军队，调兵遣将、争夺据点与资源点、攻破敌方主堡。

- 四个阵营：中国、日本、罗马、波斯，各有 7 个兵种与专属特性
- 全 3D 画面：透视镜头可平移、缩放、旋转，立体地形与河流，实时光照与阴影
- 同屏数千单位：模拟层用 SoA + 空间网格 + 共享流场寻路；渲染层把骨骼动画烘焙进贴图，每个兵种一次实例化绘制
- 程序化大地图（320×320 格）：河流、浅滩、桥、森林、丘陵、山脉；城池、城镇、营地、村庄、马场、工坊
- 所有建筑均可破坏；城墙挡路时部队会自动攻城
- 占领据点后，援军定时从据点里出来（可设集结点让他们自动开赴）；据点同时产粮，粮草不足士气就垮
- 士气与溃逃、等级与经验、行军 / 战斗两种状态，骑兵冲锋、枪兵立枪、盾兵举盾
- 昼夜与天气：夜里视野缩小、可打火把，据点入夜自动升起火把；下雨拖慢行军，偶尔下雪；雨雪天常起风，顺风行军快、顶风慢
- 资源点（农庄、伐木场、采石场、金矿）占领后自动采集：黄金把兵种升为重甲的高级形态，石料 / 木材升级城邦 / 营寨，
  木材还能给资源点和村庄建箭塔、让部队在野外扎营
- 城邦的石墙可以驻守，只有器械和战象能破；士兵打建筑是扔火把
- 单机对战 AI，另有观战模式（AI 对 AI）
- 士兵、器械、战象、建筑、树石全部由代码按真人比例建模并生成动作，四个阵营各有盔甲、头盔、盾牌与主堡样式；只有马用了一个 CC0 模型（见「素材」）

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查并打包到 dist/
npm test         # 无头模拟测试
```

需要支持 WebGL2 的桌面浏览器。

开发用预览页：`/?view=units` 查看全部兵种模型与动作（`&k=legion` 只看某个兵种及其高级形态，
`&cmp=1` 把每个兵种的初级、高级形态并排站着对比，`&clip=<动作名>` 固定播放某个动作）；
`/?view=gltf&gltf=quaternius/horse.glb` 预览任意 glTF 模型经通用流程烘焙后的样子。

调试用直达参数：`/?f=china&e=japan&size=600&seed=42&fog=0&spectate=1`
（`f`/`e` 取 `china`、`japan`、`rome`、`persia`；`d` 为难度 0–2）。

开发模式下控制台里 `window.game` 是当前对局（`game.world`、`game.renderer` 可直接读写），预览页里是 `window.viewer`。
看夜晚：`R = (await import('/src/sim/content/rules.ts')).RULES` 后改 `R.env.startClock`
（时刻 = startClock + 已过秒数 ÷ `dayLength` 取小数，0.9 是深夜）；立刻换天气：`game.world.env.nextWeather = game.world.time`。

## 操作

| 操作 | 作用 |
|---|---|
| 左键点击 / 拖框 | 选择部队（Shift 加选，双击选中屏幕内同类） |
| 底部兵种卡片 | 数字是屏幕内人数；点击选中屏幕内该兵种，在卡片上拖框一次选几个兵种，Shift 加选 / 去掉，双击选中全图该兵种 |
| 右键地面 | 移动：编队行军，自动列阵（近战在前、远程居后、器械殿后） |
| 右键按住拖动 | 在按下处列阵，面朝拖动的方向（原地拖动即原地转向重排） |
| 右键敌军 / 敌方建筑 | 攻击（Ctrl+右键强攻中立建筑；带着器械时，中立的城墙、门楼、角楼直接右键就砸） |
| F + 左键 | 攻击移动：沿途遇敌即战、见敌方建筑就打，遇墙自动破城；点在敌方建筑上则直接攻打它 |
| X / H | 停止 / 坚守 |
| R + 左键 | 设置援军集结点（只对之后新出的援军有效） |
| Shift + R | 取消集结点：新出的援军留在各自的据点 |
| T | 点燃 / 熄灭所选部队的火把（夜间） |
| B + 左键 | 扎营：派所选部队到指定位置搭一座临时据点（耗木材） |
| 左键点据点（建筑或旗帜圈） | 选中据点：底部面板里升级，或给资源点、村庄建箭塔；右侧据点列表也能点 |
| 指令面板的「升级」一栏 | 「升级所选部队」；黄金 / 石料 / 木材足够时出现「部队 / 城邦 / 营寨全部升级」（范围是全图） |
| Ctrl 或 Alt+数字 / 数字 | 编队 / 选中编队（连按两次跳转镜头） |
| Shift+数字 | 追加编队：把当前选中的部队并入该队 |
| Ctrl+A | 选中全军 |
| 鼠标移到屏幕边缘、W A S D / 方向键、小地图 | 移动镜头（越靠近边缘越快；停在按钮、列表、小地图这类能点的界面上不卷屏）；滚轮缩放。小地图是圆的，随镜头旋转；己方行进中的部队到目的地有一条流动的虚线（绿：移动，红：攻击移动） |
| C | 镜头跟随所选部队，平滑地跟着部队重心走；再按一次、或手动移动镜头（卷屏、拖动、点小地图、跳转编队）即取消 |
| 中键拖动、Q / E | 旋转镜头，上下拖动调整俯角；Shift+中键拖动平移；Home 复位 |
| 空格、+ − | 暂停、调速 |
| M | 开 / 关音效 |

## 规则摘要

完整规则与全部数值见 [docs/product/](docs/product/) 下按功能分篇的文档，清单在 [docs/README.md](docs/README.md)。

- **胜负**：摧毁敌方大本营的主堡。
- **据点**：敌占的城邦、营寨要先拆毁主建筑；再肃清占领圈内的守军，派人站到中央旗帜下读秒；敌人回来读秒暂停，旗下没人则清零。
  占领后定时出援军、产粮，被毁的建筑一并修复。据点脱离交战后，倒塌的建筑会慢慢自行重建，修满之前不放箭。城池出精锐、城镇出步弓混编、营地与村庄出步兵、马场出骑兵、工坊出攻城器械。
- **城邦与营寨**：士兵和骑兵打建筑是扔火把，营寨的木栅一烧就垮；城邦的石墙只有器械与战象能破，
  门楼、角楼可以慢慢烧毁。门楼、角楼、望楼都会放箭。城邦里待命的远程步兵会自动登上自家城墙驻守（每格墙顶三人，会沿墙顶挪向射程外的敌人），别的兵种上不了墙；据点里的近战守军不出城，挨了敌方远程的打才出击。
  在自家据点里不打仗的单位慢慢回血，建筑没挨打时自行修复。
- **士气**：敌众我寡、伤亡、断粮、淋雨都会压低士气，见底的部队溃逃（头顶一面小白旗，防御大减），逃回己方据点才恢复指挥；老兵更稳，满级死战不退。
- **粮草**：据点产粮、部队吃粮，只靠大本营养不活全军。
- **昼夜天气**：夜里视野缩小，火把照得远但会暴露自己；下雨时火把点不着、行军变慢。偶尔下雪：走得更慢、看得更近，
  据点之外的部队护甲减半。据点入夜自动升起火把。
- **资源**：资源点站到旗下 6 秒即占领，之后自动采集。农庄加军粮；黄金把部队升为高级形态（生命、攻击、护甲都更高，
  外观换成全身甲），老兵优先、各兵种轮流；石料升级城邦、木材升级营寨（建筑更结实、箭塔更狠、外观加固，易主后降回），
  手里有料时建筑也修得更快；木材还能给资源点和村庄建箭塔（最多 4 座，敌人得先拆光才能占领）、让部队扎营（临时据点，
  能休整回血，被毁不重生）。会放箭的塔楼视野远得多。
- **行军与战斗**：平时慢走、遇敌才跑；一起下令的部队编成队列、按最慢的行军。除了骑兵，出手时必须站定。骑兵远距离接敌会冲锋，枪兵见骑兵冲来会立枪，盾兵遇弓箭手会举盾。
- **等级**：击杀与助攻得经验，共 5 级，每级攻击、防御各 +50%（5 级都是 ×3），不加生命和速度。只选中一个单位时底部面板显示它的全部数值。
- **音效**：刀剑、弓弦、火器、冲撞、垮塌、风雨声全部由 Web Audio 现场合成，没有音频文件。
- **地形**：高地上的远程部队射程 +12%、伤害 +15%；森林使所受远程伤害 −25% 并拖慢骑兵；浅滩可涉水但减速；道路加速。
- **兵种克制**：枪兵克骑兵与战象，骑兵克远程与器械，刀剑步兵克枪兵。
- **伤害** = 攻击 × 克制倍率 − 护甲 ×（1 − 破甲），最低为 1。

### 加一个兵种 / 换一个模型

- **加兵种**：在 `src/sim/content/units.ts` 加一行 `U(阵营, key, 名称, 类别, { 属性 }, 说明)`，
  再在 `src/render/models/catalog.ts` 里用同一个 key 登记模型，并把它写进 `factions.ts` 的编制。
  高级形态（`key_e`）的数值和重甲模型会自动生成；想单独设计外观，就在 `catalog.ts` 里另外登记 `key_e`。
- **换模型**：改 `catalog.ts` 里那一项。用现成的 glTF 模型时写成
  `{ kind: 'gltf', src: '路径.glb', height: 1.8, clips: { idle: 'Idle', walk: 'Walk', run: 'Run', attack: 'Attack', die: 'Death' } }`，
  文件放进 `public/assets/`。缺的动作会自动退到相近的；先用 `/?view=gltf&gltf=路径.glb` 看效果。
- **调规则**：数值都在 `src/sim/content/rules.ts`，改完同步改 `docs/product/` 下对应的文档。
